# 2026-11-13 PCB 모듈 핀 연결 조사

## 조사 기준과 핀 번호 읽는 법

이 문서는 `Gerber_New-Project_Loopstation-Distributed-Pullups-20261113_2026-11-13 (3) (1).zip`의 상·하면 동박, 실크, 드릴을 기준으로 작성했다. 부품 위치는 같은 폴더의 BOM/CPL과 대조했다. 기존 펌웨어의 논리적 버튼 기능을 새 PCB에 임의로 대입하지 않고 **PCB 레퍼런스와 물리적 위치**로 부품을 식별했다.

- 거버 SHA-256: `b2ff8845f8964b0f08d95b32d75d9648e7d715c4588f5b7744a647267a6ffb33`.
- `PA0`, `PB7` 등은 STM32 GPIO 이름이다. `P2.50`은 **FK743M2-IIT6 회로도에 표시된 P2 헤더의 50번 핀**이며 MCU LQFP176 패키지의 50번 핀이라는 뜻이 아니다.
- 캐리어 PCB의 `U1`은 FK743M2의 P2에, `U9`는 P3에 대응한다. 거버에는 커넥터 핀 이름/네트 이름이 없으므로 위치와 FK743M2 회로도의 신호 순서를 대조했다.
- 좌표는 거버 원본 mm 좌표이며, 부품면을 위에서 본 방향이다. X는 오른쪽으로 증가하고 Y는 아래쪽으로 음수가 된다.
- P2의 1번 기준 좌표는 `(161.290, -72.390)`, 2번은 `(161.290, -74.930)`이다. 왼쪽으로 2.54 mm 이동할 때마다 각 행의 핀 번호가 2씩 증가한다.
- P3의 1번 기준 좌표는 `(161.28974, -107.950)`, 2번은 `(161.28974, -110.490)`이다. 역시 왼쪽으로 갈수록 핀 번호가 증가한다. 범용 2×28 핀헤더의 통상적인 1번 표시를 FK743M2 핀 번호로 사용하면 안 된다.
- MCP23017의 `GPA2`/`GPB2`는 포트 A/B의 비트 2이다. 아래의 **칩 핀 번호는 SOIC/SPDIP/SSOP 28핀 기준**이다. QFN 패키지 핀 번호와 구분한다.
- MCP23017 GPIO 헤더는 거버의 `ITB/ITA` 실크와 CJMCU 계열 모듈의 `Bx/Ax` 배열을 대조했다. 제어 헤더에 가까운 열이 B, 바깥쪽 열이 A이며, 인터럽트 행 바로 옆이 비트 0이다. 실장 모듈이 이 배열과 다른 제품이면 GPIO 대응은 재확인해야 한다.

검증 범위는 제조 데이터의 배선 추적과 회로도/데이터시트 대조다. 실물 도통 측정이나 I2C 스캔으로 조립 상태까지 확인한 결과는 아니다.

## ADC1 — 포텐셔미터 7개

모두 STM32의 아날로그 입력이다. 오디오 입력용 외장 ADC인 PCM1802는 아래 SAI1 항목에 별도로 분류한다.

- **PA0 / P3.52 — ADC1_INP16** → `SLIDER1` 와이퍼. 와이퍼 패드 좌표 `(38.32402, -127.32715)`.
- **PA1 / P3.49 — ADC1_INP17** → `KNOB1` 와이퍼. 패드 좌표 `(17.78000, -24.70886)`.
- **PA2 / P3.50 — ADC1_INP14** → `SLIDER2` 와이퍼. 패드 좌표 `(92.04502, -127.32715)`.
- **PA5 / P3.48 — ADC1_INP19** → `SLIDER3` 와이퍼. 패드 좌표 `(146.78202, -127.32715)`.
- **PA6 / P3.46 — ADC1_INP3** → `SLIDER4` 와이퍼. 패드 좌표 `(201.01102, -127.32715)`.
- **PC4 / P3.44 — ADC1_INP4** → `SLIDER5` 와이퍼. 패드 좌표 `(255.24002, -127.32715)`.
- **PC0 / P3.19 — ADC1_INP10** → `KNOB2` 와이퍼. 패드 좌표 `(251.46000, -24.70912)`.

`rtos-loopstation.ioc`에도 이 7개 ADC 채널이 설정되어 있다. ADC 채널 번호와 DMA 버퍼의 변환 순서는 별개이므로 위 목록의 나열 순서를 DMA 인덱스로 사용하지 않는다.

## SAI1 — PCM1802 입력 / PCM5102A 출력

`U7`이 PCM1802 모듈, `U8`이 PCM5102A 모듈이다. 오디오 비트 클록과 프레임 클록은 두 모듈이 공유한다.

- **PE3 / P2.50 — SAI1_SD_B** ← `U7 PCM1802 DOUT`. U7 신호 헤더 왼쪽부터 6번째, 좌표 `(94.04350, -30.35300)`.
- **PE4 / P2.49 — SAI1_FS_A** → `U7 PCM1802 LRCK` + `U8 PCM5102A LCK`. U7 왼쪽부터 3번째, U8 왼쪽부터 9번째.
- **PE5 / P2.48 — SAI1_SCK_A** → `U7 PCM1802 BCK` + `U8 PCM5102A BCK`. U7 왼쪽부터 5번째, U8 왼쪽부터 7번째.
- **PE6 / P2.47 — SAI1_SD_A** → `U8 PCM5102A DIN`. U8 왼쪽부터 8번째, 좌표 `(91.51518, -25.56535)`.
- **PG7 / P2.20 — SAI1_MCLK_A** → `U7 PCM1802 SCK`(시스템 클록/MCLK). U7 왼쪽부터 1번째, 좌표 `(81.34350, -30.35300)`. 이 SCK는 BCK와 다른 라인이다.

U7의 9핀 신호 헤더는 왼쪽부터 `SCK, PDW, LRCK, FSY, BCK, DOUT, GND, 3V3, 5V`다. `PDW`와 `FSY`는 U7의 `3V3` 패드에 연결되어 있고, `5V`는 캐리어의 5V 라인에 연결된다. 모듈 내부 레귤레이터/설정 회로는 거버에 포함되지 않는다.

U8의 11핀 헤더는 왼쪽부터 `VCC, 3V3, GND, FLT, DMP, SCL, BCK, DIN, LCK, FMT, XMT`다. `VCC`와 `XMT`는 캐리어의 3.3V 라인에 연결된다. `3V3, FLT, DMP, SCL, FMT`에는 캐리어에서 별도 신호 배선을 확인하지 못했다. U8의 `SCL`은 PCM5102A 모듈의 시스템 클록 표기이며 MCP23017 버스의 I2C SCL이 아니다. 이 핀에는 PG7 MCLK가 배선되어 있지 않다.

## TIM16 — RGB LED 직렬 데이터

- **PF6 / P3.15 — TIM16_CH1 (AF1)** → `U16 74AHCT1G125` 입력 A, 칩 2번 핀.
- **U16 Y / 칩 4번 핀 — RGB 직렬 데이터** → `R19 330 Ω` → `RGB_LED1 DIN`.
- **RGB_LED1 DOUT → RGB_LED2 DIN → RGB_LED3 DIN → RGB_LED4 DIN → RGB_LED5 DIN** 순으로 연결된다. 다섯 LED가 MCU 데이터 핀 하나를 공유한다.
- **U16 /OE / 칩 1번 핀 — 출력 허용** → GND. U16과 RGB LED 전원은 5V다.

BOM의 RGB LED는 `XL-5050RGBW-2812B-HM`이다. `pcb/datasheets/SK6812MINI-012.pdf`와 부품명이 다르므로 전송 비트 수와 색상 순서를 그 PDF만으로 확정하지 않는다. 이 LED들은 MCP23017 GPIO 출력에 연결되어 있지 않다.

## SPI2 및 GPIO — GMG12864-06D LCD

`U15` LCD 커넥터는 X가 작은 쪽부터 13개 패드가 일렬로 배치되어 있다. 아래의 “패드 순번”은 이 문서에서 정의한 **왼쪽부터의 위치**이며 LCD 제조사 커넥터 핀 번호로 단정하지 않는다. 신호 의미는 거버 연결과 기존 펌웨어의 GPIO 라벨을 함께 대조했다.

- **PB10 / P3.36 — SPI2_SCK** → U15 왼쪽부터 10번째 패드, 좌표 `(143.38274, -46.99000)`.
- **PC1 / P3.20 — SPI2_MOSI** → U15 왼쪽부터 9번째 패드, 좌표 `(140.84274, -46.99000)`.
- **PD3 / P2.34 — GMG12864_CS / GPIO 출력** → U15 왼쪽부터 13번째 패드, 좌표 `(151.00300, -46.99000)`.
- **PD5 / P2.36 — GMG12864_RST / GPIO 출력** → U15 왼쪽부터 12번째 패드, 좌표 `(148.46300, -46.99000)`.
- **PD7 / P2.35 — GMG12864_DC / GPIO 출력** → U15 왼쪽부터 11번째 패드, 좌표 `(145.92300, -46.99000)`.
- **3.3V** → U15 왼쪽부터 6·8번째 패드,좌표 `(133.22300, -46.99000)`, `(138.30300, -46.99000)`.

MISO 신호는 이 LCD에 배선되어 있지 않다.

## MCP23017

### 공통 버스와 번호 체계

- **PB8 / P2.43 — I2C1_SCL (AF4)** → `U2/U3/U4/U5 SCL`, MCP23017 칩 12번 핀.
- **PB7 / P2.44 — I2C1_SDA (AF4)** ↔ `U2/U3/U4/U5 SDA`, MCP23017 칩 13번 핀.
- **VDD / 칩 9번 핀 — 3.3V**, **VSS / 칩 10번 핀 — GND**.
- **/RESET / 칩 18번 핀 — 3.3V 고정**. 주소 선택 A0/A1/A2는 각각 칩 15/16/17번 핀이다.
- 주소는 모두 **7비트 주소**다. STM32 HAL에 전달할 때 사용하는 `address << 1` 값과 구분한다.
- 아래 입력 버튼은 스위치가 GND 쪽으로 닫히는 배선이다. 엔코더 푸시의 외부 풀업을 제외한 버튼 입력에는 필요에 따라 MCP23017 내부 풀업을 설정한다.
- TS5(`U43`~`U48`)는 스위치 입력과 표시 LED 제어를 별도 라인으로 정리했다. LED 제어는 `R1`~`R6` 470 Ω을 거쳐 실크 `+` 패드에 연결된다. TS5의 부품 단자 번호는 제조 도면에서 확인하기 전까지 지정하지 않는다.

| 7비트 주소 | HAL 주소 인자 | 모듈 | A2:A1:A0 | MCU 인터럽트 연결 |
| --- | --- | --- | --- | --- |
| `0x21` | `0x42` | U5 / 왼쪽 바깥 | `001` | INTB → PI11 / P3.53 |
| `0x23` | `0x46` | U3 / 오른쪽 안쪽 | `011` | INTA → PI0 / P2.11 |

- **GPA2 / 칩 23번 핀 — 입력** → `U21` 택트 버튼(오른쪽 조작부의 오른쪽 버튼).
- **GPB2 / 칩 3번 핀 — 입력** → `U20` 택트 버튼(오른쪽 조작부의 왼쪽 버튼).
- **GPA3 / 칩 24번 핀 — 입력** → `U25` 택트 버튼(오른쪽 2×3 배열의 위쪽 오른쪽).
- **GPB3 / 칩 4번 핀 — 입력** → `U24` 택트 버튼(같은 배열의 아래쪽 오른쪽).
- **GPA4 / 칩 25번 핀 — LED 출력** → `R6` → `U48 TS5 LED +`.
- **GPB4 / 칩 5번 핀 — 입력** → `U48 TS5` 스위치(오른쪽 TS5 3개 중 오른쪽).
- **GPA5 / 칩 26번 핀 — LED 출력** → `R5` → `U47 TS5 LED +`.
- **GPB5 / 칩 6번 핀 — 입력** → `U47 TS5` 스위치(오른쪽 TS5 3개 중 가운데).
- **GPA6 / 칩 27번 핀 — LED 출력** → `R4` → `U46 TS5 LED +`.
- **GPB6 / 칩 7번 핀 — 입력** → `U46 TS5` 스위치(오른쪽 TS5 3개 중 왼쪽).
- **INTB / 칩 19번 핀 — 인터럽트 출력** → **PF8 / P3.17 / EXTI8**.
- **미사용 GPIO**: GPA0(칩 21번), GPA7(칩 28번), GPB7(칩 8번). INTA에는 MCU 배선이 없다.

### 인터럽트 설정 시 주의할 실제 배선

각 모듈은 A 또는 B 인터럽트 중 하나만 MCU에 연결된다. 양쪽 포트의 버튼을 모두 인터럽트로 처리하려면 `IOCON.MIRROR=1`로 A/B 인터럽트를 결합해야 한다. 예를 들어 U5는 INTB만 배선되어 있으므로 MIRROR를 끄면 GPA2의 U17 입력 변경이 MCU 인터럽트로 전달되지 않는다.

U3의 PI0, U2의 PH4, U4의 PF8, U5의 PI11은 각각 서로 다른 EXTI 라인을 사용한다. `Core/Inc/main.h`의 기존 PB0/PB1 MCP23017 인터럽트 정의와는 일치하지 않는다.

## 아날로그 오디오 — XLR / TS472 / PCM1802

이 구간은 MCU ADC1에 직접 들어가지 않고 외장 오디오 ADC 모듈로 들어간다.

- **P1 XLR 1번 — 실드/접지 라인** → `U6 TS472` 왼쪽 입력 헤더 `GND` 패드 `(49.403, -32.893)`.
- **P1 XLR 2번 — 마이크 + 라인** → `U6 TS472 IN+` 패드 `(51.943, -32.893)`.
- **P1 XLR 3번 — 마이크 − 라인** → `U6 TS472 IN−` 패드 `(54.483, -32.893)`.
- **U6 OUT+ — 아날로그 오디오** → `U7 PCM1802` 아날로그 입력 패드 `(82.61350, -46.86300)`.
- **U6 OUT−** → 패드 `(51.943, -53.213)`에 캐리어 배선을 확인하지 못했다.
- **U6 VCC / GND** → 캐리어 5V / GND. PCM1802 아날로그 입력 두 패드 중 `(82.61350, -41.78300)`에는 캐리어 배선을 확인하지 못했다.

PCM1802의 연결된 아날로그 입력을 L/R 중 어느 채널로 부르는지는 이 거버 실크만으로 확정하지 않았다. XLR 번호는 P1 풋프린트와 `NC3FAAH-0.pdf`의 단자 배치를 대조한 값이다. 모듈 자체의 내부 연결 및 XLR 실물 단자 번호는 조립 시 해당 부품의 표기를 우선한다.

## 기존 펌웨어와의 차이 및 확인 범위

- 기존 MCP23017 설정은 `0x24/0x25` 두 주소를 중심으로 되어 있으나 새 PCB는 `0x21/0x23/0x25/0x27` 네 모듈이다. 같은 `0x25`라도 기존 버튼 맵과 동일하다고 볼 수 없다.
- 엔코더 회전 입력 TIM3/TIM2/TIM8/TIM5 및 LCD 신호 이름은 현재 GPIO/MSP 설정과 대조했다. 엔코더 푸시는 네 개 모두 `0x23`으로 모인다.
- 25개 택트 버튼, TS5 스위치 6개와 LED 6개, 엔코더 푸시 4개를 MCP23017 항목에 정리했다. 트랙 번호는 PCB의 왼쪽부터 1~5로 정의했다. 위/가운데/아래 버튼의 재생·정지·편집 같은 논리 기능은 이 문서에서 지정하지 않았다.
- MCP23017의 주소 선택과 미사용 핀/GND 구분에는 하면 동박의 GND 폴리곤도 대조했다. 단순히 “배선이 보이지 않는다”는 이유로 주소 선택 핀을 LOW로 가정하지 않았다.
- 거버는 모듈 내부 회로와 실제 실장 상태를 포함하지 않는다. 캐리어 배선이 없는 모듈 설정 핀의 내부 풀업/풀다운이나 L/R 채널, TS5 제조사 단자 번호는 미확정으로 남겼다.
- SDMMC, QSPI Flash, FMC SDRAM 등 FK743M2 자체 부품은 캐리어 모듈 배선 조사 범위에 포함하지 않았다. 펌웨어 코드는 변경하지 않았다.
