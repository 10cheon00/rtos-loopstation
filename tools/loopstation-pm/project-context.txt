프로젝트: RTOS 기반 루프스테이션
개발자: 김택천. 펌웨어 구현과 실제 하드웨어 검증, 최종 기술 판단 담당.
PM: 우선순위와 작업 목표, 시간 배분안을 먼저 제시하고 개발자와 조율한다.

2026-09-15 개발자가 공유한 상태 (저장소를 직접 검토한 결과가 아님)
- 브레드보드 검증 하드웨어에서 만능기판에 모듈을 납땜한 하드웨어로 전환 중.
- 엔코더 4개 납땜과 정상 동작 확인 완료. 테스트를 위해 타이머 4개 추가.
- 개발 보드 변경과 핀헤더 연결 제약 때문에 페리퍼럴 및 핀 재배치.
- 비오디오 기존 하드웨어 테스트 성공. GPIO 설정 변경과 MCP23017 임시 초기화 코드 추가.
- PCM5102A 출력 모듈과 INMP441 입력 모듈은 암소켓 부족으로 미납땜. 9/16 작업 예정.
- 두 오디오 모듈의 납땜은 합계 약 1시간이라는 개발자 추정. 테스트 코드가 없어 검증 소요시간은 미확정.
- 해당 주 수·목·금(9/16~9/18)에 하루 6시간씩, 총 18시간 작업 가능.
- 개발자가 제시한 오디오 성공 기준은 실제 입력→출력 패스스루 동작 확인.
- 보드 변경 후 SDRAM은 아직 테스트하지 않음. 개발자 기준은 보드의 32MB RAM 인식과 읽기·쓰기 가능 확인.
- SDRAM 검증은 별도 프로젝트로 진행 가능하므로 오디오보다 우선순위를 낮춰도 됨.
- 이후 후보는 오디오 처리 파이프라인 기능 구현 또는 패널 마무리. 현재 남은 작업량은 미공유.
위 상태는 해당 날짜 기준이다. 이후 대화에서 변경되면 최신 정보를 우선한다.
