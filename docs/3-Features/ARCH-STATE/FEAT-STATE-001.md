# 상태 머신 등록부

## 1. 기능 범위

| 항목 | 내용 |
| --- | --- |
| 기능 ID | `FEAT-STATE-001` |
| 상위 설계 문서 | `ARCH-STATE.md` |
| 관련 설계 항목 | `ARCH-STATE-001` |
| 관련 요구사항 | `REQ-STATE-001` |
| 주요 목적 | 정적으로 구성된 상태 머신 인스턴스를 식별자별로 등록하고 조회한다. |
| 제외 범위 | 개별 상태 머신의 전이 조건과 상태별 동작 |

## 2. 연결된 상위 설계 항목

| 설계 항목 ID | 설계 항목 | 연결 내용 |
| --- | --- | --- |
| `ARCH-STATE-001` | 상태 머신 등록부 | 정적으로 구성된 상태 머신 인스턴스를 식별자별로 등록하고 조회한다. |

## 3. 목적

정적으로 구성된 상태 머신 인스턴스를 식별자별로 등록하고 조회한다.

## 4. 입력

| 입력 | 설명 |
| --- | --- |
| 상태 머신 식별자 | 상태 머신 종류 ID |
| 인스턴스 식별자 | 같은 종류의 인스턴스 ID |
| 인스턴스 참조 | 정적 수명의 등록 대상 |

## 5. 출력

| 출력 | 설명 |
| --- | --- |
| 등록 결과 | 정상, 중복 또는 용량 오류 |
| 인스턴스 참조 | 식별자로 조회한 대상 |

## 6. 구현 기준

| 항목 | 기준 |
| --- | --- |
| 정적 구성 | 등록부 최대 크기는 컴파일 시 결정한다. |
| 식별자 유일성 | machine ID와 instance ID 조합은 유일해야 한다. |
| 조회 실패 | 미등록 대상은 명시적 실패로 반환한다. |
| 소유권 | 등록부는 인스턴스를 생성하거나 해제하지 않는다. |

## 7. 완료 기준

| 기준 | 확인 방법 |
| --- | --- |
| 정상 등록 | 복수 인스턴스가 식별자별로 조회되는지 확인한다. |
| 중복 방지 | 같은 식별자 조합의 등록이 거부되는지 확인한다. |
| 용량 오류 | 등록부 초과가 오류로 반환되는지 확인한다. |
