# 최초 상태 진입

## 1. 기능 범위

| 항목 | 내용 |
| --- | --- |
| 기능 ID | `FEAT-STATE-006` |
| 상위 설계 문서 | `ARCH-STATE.md` |
| 관련 설계 항목 | `ARCH-STATE-006` |
| 관련 요구사항 | `REQ-STATE-002` |
| 주요 목적 | 등록 완료 후 첫 이벤트보다 먼저 초기 상태의 on_enter를 정확히 한 번 호출한다. |
| 제외 범위 | 이후 상태 전이의 on_enter 호출 |

## 2. 연결된 상위 설계 항목

| 설계 항목 ID | 설계 항목 | 연결 내용 |
| --- | --- | --- |
| `ARCH-STATE-006` | 최초 진입 | 등록 완료 후 첫 이벤트보다 먼저 초기 상태의 on_enter를 정확히 한 번 호출한다. |

## 3. 목적

등록 완료 후 첫 이벤트보다 먼저 초기 상태의 on_enter를 정확히 한 번 호출한다.

## 4. 입력

| 입력 | 설명 |
| --- | --- |
| 초기화된 인스턴스 | 초기 상태가 설정된 상태 머신 |
| 초기 진입 원인 | 상태 머신 시작 원인 |

## 5. 출력

| 출력 | 설명 |
| --- | --- |
| 진입 처리 결과 | on_enter 성공 또는 오류 |
| 활성화 상태 | 이벤트 수신 가능 여부 |

## 6. 구현 기준

| 항목 | 기준 |
| --- | --- |
| 호출 횟수 | 초기 활성화에서 on_enter를 한 번 호출한다. |
| 호출 순서 | 등록 후 첫 on_message 전에 호출한다. |
| 실패 처리 | on_enter 실패 시 활성화하지 않는다. |
| 재호출 방지 | 활성화된 인스턴스에는 다시 적용하지 않는다. |

## 7. 완료 기준

| 기준 | 확인 방법 |
| --- | --- |
| 순서 검증 | on_enter가 첫 on_message보다 앞서는지 확인한다. |
| 단일 호출 | 정상 초기화에서 한 번 호출되는지 확인한다. |
| 실패 경로 | on_enter 오류 시 dispatch가 차단되는지 확인한다. |
