# 상태 이벤트 분류

## 1. 기능 범위

| 항목 | 내용 |
| --- | --- |
| 기능 ID | `FEAT-STATE-009` |
| 상위 설계 문서 | `ARCH-STATE.md` |
| 관련 설계 항목 | `ARCH-STATE-009` |
| 관련 요구사항 | `REQ-STATE-003` |
| 주요 목적 | StateEvent의 type과 payload를 조사해 대상 상태 머신 종류와 인스턴스를 결정한다. |
| 제외 범위 | 대상 상태의 on_message와 도메인 이벤트 처리 |

## 2. 연결된 상위 설계 항목

| 설계 항목 ID | 설계 항목 | 연결 내용 |
| --- | --- | --- |
| `ARCH-STATE-009` | 이벤트 분류 | StateEvent의 type과 payload를 조사해 대상 상태 머신 종류와 인스턴스를 결정한다. |

## 3. 목적

StateEvent의 type과 payload를 조사해 대상 상태 머신 종류와 인스턴스를 결정한다.

## 4. 입력

| 입력 | 설명 |
| --- | --- |
| 검증된 StateEvent | 분류 대상 |
| 이벤트 분류표 | 대상 결정 규칙 |
| 상태 머신 등록부 | 인스턴스 조회 정보 |

## 5. 출력

| 출력 | 설명 |
| --- | --- |
| 대상 machine ID | 처리 도메인 |
| 대상 instance ID | 실제 처리 인스턴스 |
| 분류 결과 | 성공 또는 오류 |

## 6. 구현 기준

| 항목 | 기준 |
| --- | --- |
| 명시적 규칙 | type과 정의된 payload 멤버만 사용한다. |
| 결정성 | 같은 입력은 같은 대상을 만든다. |
| 단일 대상 기본 | 별도 정책이 없으면 한 인스턴스로 분류한다. |
| 미분류 처리 | 대상 없는 이벤트를 임의 전달하지 않는다. |

## 7. 완료 기준

| 기준 | 확인 방법 |
| --- | --- |
| 도메인 분류 | 대표 이벤트의 machine ID를 확인한다. |
| 인스턴스 분류 | track_id 등이 반영되는지 확인한다. |
| 미분류 오류 | 필수 ID가 없을 때 실패하는지 확인한다. |

## 8. 구현 및 검증 상태

| 항목 | 상태 | 날짜 | 비고 |
| --- | --- | --- | --- |
| 구현 | 미구현 | - | 기능 명세에 따른 구현이 필요하다. |
| 검증 | 미검증 | - | 구현 완료 후 완료 기준에 따라 검증한다. |
