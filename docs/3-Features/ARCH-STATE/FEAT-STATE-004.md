# 정적 상태 인스턴스

## 1. 기능 범위

| 항목 | 내용 |
| --- | --- |
| 기능 ID | `FEAT-STATE-004` |
| 상위 설계 문서 | `ARCH-STATE.md` |
| 관련 설계 항목 | `ARCH-STATE-004` |
| 관련 요구사항 | `REQ-STATE-002` |
| 주요 목적 | 상태 정의를 정적 수명으로 제공하여 런타임 동적 할당 없이 참조를 전환한다. |
| 제외 범위 | 상태별 생명주기 동작 내용 |

## 2. 연결된 상위 설계 항목

| 설계 항목 ID | 설계 항목 | 연결 내용 |
| --- | --- | --- |
| `ARCH-STATE-004` | 정적 상태 인스턴스 | 상태 정의를 정적 수명으로 제공하여 런타임 동적 할당 없이 참조를 전환한다. |

## 3. 목적

상태 정의를 정적 수명으로 제공하여 런타임 동적 할당 없이 참조를 전환한다.

## 4. 입력

| 입력 | 설명 |
| --- | --- |
| 상태 정의 | 상태 ID와 생명주기 인터페이스 |
| 상태 목록 | 머신별 허용 상태 참조 집합 |

## 5. 출력

| 출력 | 설명 |
| --- | --- |
| 정적 상태 인스턴스 | 프로그램 수명 동안 유효한 상태 정의 |
| 허용 상태 집합 | 전이 검증용 참조 목록 |

## 6. 구현 기준

| 항목 | 기준 |
| --- | --- |
| 동적 할당 금지 | 상태 생성에 heap API를 사용하지 않는다. |
| 불변 정의 | 상태 ID와 함수 포인터는 초기화 후 바꾸지 않는다. |
| 정적 수명 | 모든 상태 참조는 스케줄러 실행 중 유효해야 한다. |
| context 분리 | mutable 데이터는 상태 객체에 저장하지 않는다. |

## 7. 완료 기준

| 기준 | 확인 방법 |
| --- | --- |
| heap 미사용 | 상태 경로에 동적 할당 호출이 없는지 확인한다. |
| 수명 검증 | 모든 상태가 정적 수명인지 확인한다. |
| 공유 검증 | 상태 정의 공유 시 인스턴스 context가 섞이지 않는지 확인한다. |
