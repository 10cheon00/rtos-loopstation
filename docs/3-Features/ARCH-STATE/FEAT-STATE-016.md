## 2. 연결된 상위 설계 항목

## 3. 목적

전이 검증과 on_exit 완료 후 canonical state 참조를 한 번만 변경한다.

## 4. 입력

| 입력 | 설명 |
| --- | --- |
| 검증된 전이 정보 | 현재와 다음 상태 |
| on_exit 결과 | commit 선행 조건 |
| 상태 머신 인스턴스 | canonical state 소유자 |

## 5. 출력

| 출력 | 설명 |
| --- | --- |
| commit된 상태 | 다음 상태 참조 |
| commit 여부 | 오류 분석 정보 |

## 6. 구현 기준

| 항목 | 기준 |
| --- | --- |
| 선행 조건 | 검증과 on_exit이 성공해야 한다. |
| 단일 대입 | 한 지점에서 current state를 변경한다. |
| 중간 노출 방지 | commit 전 다음 상태를 외부에 노출하지 않는다. |
| 전이 기록 | 이전과 다음 상태 ID를 보존한다. |

## 7. 완료 기준

| 기준 | 확인 방법 |
| --- | --- |
| 선행 실패 | 실패에서 commit이 없는지 확인한다. |
| 정상 commit | 한 번만 목적 상태로 바뀌는지 확인한다. |
| 전이 기록 | 이전과 다음 ID가 남는지 확인한다. |
