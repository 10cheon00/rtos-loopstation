# 현재 상태 메시지 위임

## 1. 기능 범위

| 항목 | 내용 |
| --- | --- |
| 기능 ID | `FEAT-STATE-010` |
| 상위 설계 문서 | `ARCH-STATE.md` |
| 관련 설계 항목 | `ARCH-STATE-010` |
| 관련 요구사항 | `REQ-STATE-003` |
| 주요 목적 | 분류된 인스턴스의 현재 상태가 구현한 on_message에 context와 이벤트를 전달한다. |
| 제외 범위 | on_message 내부 동작과 상태 전이 실행 |

## 2. 연결된 상위 설계 항목

| 설계 항목 ID | 설계 항목 | 연결 내용 |
| --- | --- | --- |
| `ARCH-STATE-010` | 메시지 위임 | 분류된 인스턴스의 현재 상태가 구현한 on_message에 context와 이벤트를 전달한다. |

## 3. 목적

분류된 인스턴스의 현재 상태가 구현한 on_message에 context와 이벤트를 전달한다.

## 4. 입력

| 입력 | 설명 |
| --- | --- |
| 대상 인스턴스 | 조회된 상태 머신 |
| StateEvent | 현재 상태에 전달할 이벤트 |

## 5. 출력

| 출력 | 설명 |
| --- | --- |
| 상태 처리 결과 | 공통 결과 값 |
| 다음 상태 참조 | TRANSITION 목적 상태 |

## 6. 구현 기준

| 항목 | 기준 |
| --- | --- |
| 현재 상태 snapshot | 호출 시작 시 current state를 한 번 읽는다. |
| context 전달 | 인스턴스 전용 context를 사용한다. |
| null 방지 | 상태나 함수가 무효하면 ERROR를 반환한다. |
| 결과 보존 | on_message 반환값을 변경 없이 전달한다. |

## 7. 완료 기준

| 기준 | 확인 방법 |
| --- | --- |
| 정상 위임 | 현재 상태 on_message 호출을 확인한다. |
| context 분리 | 복수 인스턴스에 올바른 context가 전달되는지 확인한다. |
| 무효 인터페이스 | HardFault 없이 ERROR가 반환되는지 확인한다. |
