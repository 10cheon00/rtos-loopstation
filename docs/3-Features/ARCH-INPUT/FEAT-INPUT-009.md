# FEAT-INPUT-009: 버튼 입력 오류 기록

## 1. 연결된 상위 설계 항목

| 설계 항목 식별자 | 설계 항목 설명 |
| --- | --- |
| `ARCH-INPUT-031` | 버튼의 접점 흔들림을 제거하고 안정된 눌림/떼짐 이벤트를 만든다. |
| `ARCH-INPUT-035` | 변환된 입력 이벤트를 발생 순서대로 상태 관리 구조에 전달한다. |

## 2. 설명

버튼 입력 경로에서 발생한 큐 포화, 장치·핀 식별 실패, I2C 통신 실패, 상태 이벤트 전송 실패를 종류별로 기록한다.

## 3. 입력

| 입력 | 설명 |
| --- | --- |
| `osStatus_t` | `input_event_queue`와 `state_event_queue`의 전송 결과 |
| `Mcp23017Status` | MCP23017 레지스터 읽기 결과 |
| `TaskStatus` | 장치 주소와 `ControlButtonId` 조회 결과 |

## 4. 출력

| 출력 | 설명 |
| --- | --- |
| 오류별 누적 횟수 | 큐 포화, 매핑 실패, I2C 실패, 상태 이벤트 전송 실패의 발생 횟수 |
| 마지막 오류 | 가장 최근에 발생한 입력 처리 오류 종류 |

## 5. 구현 기준

| 항목 | 기준 |
| --- | --- |
| 오류 구분 | 입력 큐 전송, 장치 조회, 버튼 매핑, I2C 읽기, 상태 큐 전송 오류를 구분한다. |
| ISR 기록 | ISR에서는 대기나 복잡한 처리를 하지 않고 큐 전송 실패 횟수만 안전하게 증가시킨다. |
| 태스크 기록 | `InputTask`에서 확인한 오류는 종류별 누적 횟수와 마지막 오류에 반영한다. |
| 정상 경로 | 진단 기록이 정상 입력 이벤트의 순서와 내용에 영향을 주지 않아야 한다. |

## 6. 구현 및 검증 상태

| 항목 | 상태 | 날짜 | 비고 |
| --- | --- | --- | --- |
| 구현 | 미구현 | - | 오류 종류와 진단 저장소가 정의되어 있지 않다. |
| 검증 | 미완료 | - | 구현 후 각 오류를 주입해 기록값을 검증한다. |
