# FEAT-INPUT-010: 아날로그 조작값 샘플링

## 1. 연결된 상위 설계 항목

| 설계 항목 식별자 | 설계 항목 설명 |
| --- | --- |
| `ARCH-INPUT-011` | FX부 아날로그 조작값을 정해진 주기로 읽는다. |
| `ARCH-INPUT-016` | 트랙부 아날로그 조작값을 공통 아날로그 입력 경로로 읽는다. |
| `ARCH-INPUT-033` | 아날로그 값을 주기적으로 읽고 최소 변화량과 전송 주기를 적용해 의미 있는 변경만 만든다. |

## 2. 설명

FX부와 트랙부의 ADC 채널을 조작기 식별자에 연결하고 정해진 주기로 원시값을 읽는다.

## 3. 입력

| 입력 | 설명 |
| --- | --- |
| `ADC_HandleTypeDef` | 아날로그 변환에 사용하는 ADC 핸들 |
| ADC 채널 설정 | ADC 채널과 조작기 식별자의 정적 매핑 |
| `TickType_t` | 다음 샘플 시점을 결정하는 RTOS tick |

## 4. 출력

| 출력 | 설명 |
| --- | --- |
| 조작기 식별자 | 샘플을 발생시킨 포텐셔미터 식별자 |
| ADC 원시값 | 설정된 ADC 해상도 범위의 샘플 값 |
| 샘플 시각 | 원시값을 읽은 RTOS tick |

## 5. 구현 기준

| 항목 | 기준 |
| --- | --- |
| 채널 매핑 | ADC 채널과 조작기 식별자의 관계를 정적 설정으로 정의한다. |
| 샘플 주기 | 모든 대상 채널을 설정된 주기로 읽고 불필요한 busy wait를 사용하지 않는다. |
| 책임 제한 | 원시값의 변화 의미를 판단하거나 파라미터 저장소를 수정하지 않는다. |
| 오류 전달 | ADC 변환 실패를 후속 진단 기능이 구분할 수 있게 반환한다. |

## 6. 구현 및 검증 상태

| 항목 | 상태 | 날짜 | 비고 |
| --- | --- | --- | --- |
| 구현 | 미구현 | - | ADC 초기화는 있으나 채널 매핑과 주기적 샘플링 코드가 없다. |
| 검증 | 미완료 | - | 구현 후 모든 채널의 샘플 주기와 원시값 범위를 검증한다. |
