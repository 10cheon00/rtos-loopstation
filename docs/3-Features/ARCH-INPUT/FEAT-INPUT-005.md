# FEAT-INPUT-005: 버튼 debounce 판정

## 1. 연결된 상위 설계 항목

| 설계 항목 식별자 | 설계 항목 설명 |
| --- | --- |
| `ARCH-INPUT-002` | 접점 흔들림을 제거하고 안정된 눌림/떼짐 변화를 확정한다. |
| `ARCH-INPUT-006` | IFX/TFX 버튼의 상태 변화를 공통 버튼 입력 경로로 감지한다. |
| `ARCH-INPUT-026` | 엔코더 누름 버튼 상태를 공통 버튼 입력 경로로 읽는다. |
| `ARCH-INPUT-031` | 버튼의 접점 흔들림을 제거하고 안정된 눌림/떼짐 이벤트를 만든다. |

## 2. 설명

MCP23017에서 읽은 버튼 상태의 접점 흔들림을 제거하고 실제 눌림 또는 떼짐으로 확정된 변화만 후속 기능에 전달한다.

## 3. 입력

| 입력 | 설명 |
| --- | --- |
| `ControlButtonId` | 상태를 판정할 버튼 식별자 |
| `ControlButtonState` | MCP23017에서 읽은 현재 버튼 상태 |
| `TickType_t timestamp_ticks` | 버튼 상태가 감지된 시각 |

## 4. 출력

| 출력 | 설명 |
| --- | --- |
| 안정된 `ControlButtonState` | debounce 시간이 지난 뒤 확정된 버튼 상태 |
| 상태 변경 여부 | 새로운 버튼 이벤트를 생성해야 하는지 나타내는 결과 |

## 5. 구현 기준

| 항목 | 기준 |
| --- | --- |
| 상태 보관 | 버튼별 최근 raw 상태, 확정 상태, 마지막 변경 tick을 보관한다. |
| 확정 조건 | 같은 raw 상태가 정해진 debounce 시간 동안 유지될 때만 확정 상태를 변경한다. |
| 중복 제거 | 확정 상태가 이전과 같으면 후속 버튼 이벤트를 생성하지 않는다. |
| 독립 처리 | 각 `ControlButtonId`의 debounce 상태는 서로 영향을 주지 않아야 한다. |

## 6. 구현 및 검증 상태

| 항목 | 상태 | 날짜 | 비고 |
| --- | --- | --- | --- |
| 구현 | 미구현 | - | 버튼별 debounce 상태와 시간 판정 코드가 없다. |
| 검증 | 미완료 | - | 구현 후 press/release와 접점 흔들림 입력으로 검증한다. |
