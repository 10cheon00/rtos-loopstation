# FEAT-INPUT-006: 버튼 상태 스냅샷

## 1. 연결된 상위 설계 항목

| 설계 항목 식별자 | 설계 항목 설명 |
| --- | --- |
| `ARCH-INPUT-022` | 접점 흔들림 제거가 끝난 버튼별 눌림/떼짐 상태를 보관한다. |
| `ARCH-INPUT-023` | 회전 시점에 눌린 보조 버튼 상태를 현재 버튼 상태 모음에서 복사한다. |
| `ARCH-INPUT-027` | 확정된 엔코더 누름 상태를 현재 버튼 상태 모음에 반영한다. |
| `ARCH-INPUT-030` | 현재 엔코더 누름 상태를 회전 이벤트의 보조 버튼 정보로 제공한다. |
| `ARCH-INPUT-032` | 접점 흔들림 제거가 끝난 버튼 상태를 보관하고 엔코더 회전 시점에 복사한다. |

## 2. 설명

debounce가 끝난 버튼 상태를 입력 계층의 스냅샷으로 보관한다.
엔코더 회전 이벤트는 회전 시점의 스냅샷에서 눌린 보조 버튼 정보를 가져간다.

## 3. 입력

| 입력 | 설명 |
| --- | --- |
| `ControlButtonId` | 상태가 변경된 버튼 식별자 |
| `ControlButtonState` | 확정된 버튼 눌림 또는 떼짐 상태 |

## 4. 출력

| 출력 | 설명 |
| --- | --- |
| `button_state_snapshot` | 현재 눌린 버튼을 조회할 수 있는 입력 계층 상태 |
| `modifier_mask` | 엔코더 회전 시점에 복사한 보조 버튼 상태 |

## 5. 구현 기준

| 항목 | 기준 |
| --- | --- |
| 갱신 | `PRESSED`이면 해당 버튼을 설정하고 `RELEASED`이면 해제한다. |
| 갱신 시점 | debounce로 상태 변화가 확정된 경우에만 스냅샷을 변경한다. |
| 소유권 | 스냅샷은 `InputTask`가 소유하며 상태 관리 구조의 상태로 사용하지 않는다. |
| 원자성 | 스냅샷 조회 중 갱신으로 일관되지 않은 `modifier_mask`가 만들어지지 않아야 한다. |

## 6. 구현 및 검증 상태

| 항목 | 상태 | 날짜 | 비고 |
| --- | --- | --- | --- |
| 구현 | 미구현 | - | `InputTaskContext`에는 엔코더 카운터만 있고 버튼 상태 스냅샷이 없다. |
| 검증 | 미완료 | - | 구현 후 버튼 press/release와 회전 시점 복사를 검증한다. |
