# FEAT-INPUT-013: 아날로그 값 정규화

## 1. 연결된 상위 설계 항목

| 설계 항목 식별자 | 설계 항목 설명 |
| --- | --- |
| `ARCH-INPUT-013` | 원시값을 후속 구조가 공통으로 사용할 수 있는 범위로 정규화한다. |
| `ARCH-INPUT-018` | 원시값을 후속 구조가 공통으로 사용할 수 있는 범위로 정규화한다. |

## 2. 설명

의미 있는 ADC 원시값을 후속 구조가 장치별 ADC 해상도를 몰라도 사용할 수 있는 공통 범위로 변환한다.

## 3. 입력

| 입력 | 설명 |
| --- | --- |
| ADC 원시값 | 의미 있는 변화로 확정된 샘플 값 |
| ADC 최소·최대값 | 입력 원시 범위 |
| 정규화 최소·최대값 | 후속 이벤트가 사용하는 출력 범위 |

## 4. 출력

| 출력 | 설명 |
| --- | --- |
| 정규화된 값 | 후속 구조가 공통으로 사용하는 범위의 아날로그 값 |

## 5. 구현 기준

| 항목 | 기준 |
| --- | --- |
| 범위 변환 | ADC 최소·최대값을 정규화 최소·최대값에 일관되게 대응시킨다. |
| clamp | 입력 또는 계산 결과가 범위를 벗어나면 가장 가까운 경계값으로 제한한다. |
| 정밀도 | 중간 계산 overflow와 불필요한 정밀도 손실을 방지할 정수 폭을 사용한다. |
| 책임 제한 | 파라미터별 최소·최대값이나 현재 UI 패널을 조회하지 않는다. |

## 6. 구현 및 검증 상태

| 항목 | 상태 | 날짜 | 비고 |
| --- | --- | --- | --- |
| 구현 | 미구현 | - | ADC 원시값을 공통 범위로 변환하는 코드가 없다. |
| 검증 | 미완료 | - | 입력 범위의 최소, 중간, 최대와 범위 밖 값을 검증한다. |
