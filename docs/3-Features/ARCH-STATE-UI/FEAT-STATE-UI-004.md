# FEAT-STATE-UI-004: 최초 홈 패널 렌더링 조정
## 1. 연결된 상위 설계 항목
| 설계 항목 식별자 | 설계 항목 설명 |
| --- | --- |
| `ARCH-STATE-UI-004` | 초기 상태 진입 후 StateTask가 홈 패널의 최초 렌더링을 요청한다. |
## 2. 설명
HOME 진입 완료 후 StateTask가 홈 패널 ID와 바인딩 파라미터로 최초 표시 명령을 만든다.
## 3. 입력
| 입력 | 설명 |
| --- | --- |
| `UI_PANEL_ID_HOME`, `UiPanelParameterBinding` | 초기 패널과 표시값 관계 |
## 4. 출력
| 출력 | 설명 |
| --- | --- |
| `DISPLAY_COMMAND_UI_STATE_RENDER` | 최초 홈 화면 명령 |
## 5. 구현 기준
| 항목 | 기준 |
| --- | --- |
| 시점 | HOME `on_enter()` 성공 직후 한 번 요청한다. |
| 책임 | UI 상태의 생명주기 함수는 표시 queue에 접근하지 않는다. |
## 6. 구현 및 검증 상태
| 항목 | 상태 | 날짜 | 비고 |
| --- | --- | --- | --- |
| 구현 | 미구현 | - | StateTask는 초기 HOME 진입 후 최초 렌더링을 요청하지 않는다. |
| 검증 | 미완료 | - | 시작 직후 HOME 화면 출력을 검증한다. |
