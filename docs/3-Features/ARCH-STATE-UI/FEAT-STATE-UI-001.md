# FEAT-STATE-UI-001: UI 패널 상태 모델
## 1. 연결된 상위 설계 항목
| 설계 항목 식별자 | 설계 항목 설명 |
| --- | --- |
| `ARCH-STATE-UI-001` | 각 UI 패널을 고유한 `UiPanelId`를 가진 정적 상태로 등록한다. |
## 2. 설명
각 UI 패널을 `State` 인스턴스로 정의하고 `UiPanelId`로 조회할 수 있게 한다.
## 3. 입력
| 입력 | 설명 |
| --- | --- |
| `State`, `UiPanelId` | 패널 상태와 고유 식별자 |
## 4. 출력
| 출력 | 설명 |
| --- | --- |
| `ui_state_ui_panel_id_mappings` | panel ID로 조회 가능한 정적 상태 목록 |
## 5. 구현 기준
| 항목 | 기준 |
| --- | --- |
| 정적 생성 | 모든 상태를 정적으로 생성하고 동적 할당하지 않는다. |
| 완전성 | 모든 유효 `UiPanelId`에 정확히 하나의 `State`를 연결한다. |
## 6. 구현 및 검증 상태
| 항목 | 상태 | 날짜 | 비고 |
| --- | --- | --- | --- |
| 구현 | 부분 구현 | - | HOME과 SETTING 상태 및 매핑만 존재한다. |
| 검증 | 미완료 | - | 전체 패널 ID 매핑과 무효 ID를 검증해야 한다. |
