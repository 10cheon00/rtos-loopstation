# FEAT-STATE-UI-014: 하위 패널 전이 후 렌더링
## 1. 연결된 상위 설계 항목
| 설계 항목 식별자 | 설계 항목 설명 |
| --- | --- |
| `ARCH-STATE-UI-014` | StateTask가 하위 패널 전이 완료 후 새 패널 렌더링을 요청한다. |
## 2. 설명
StateTask가 Enter 전이를 마친 뒤 하위 panel ID와 바인딩 파라미터를 표시 명령으로 전송한다.
## 3. 입력
| 입력 | 설명 |
| --- | --- |
| transition flag, 하위 `UiPanelId` | 처리 결과와 전이된 패널 |
## 4. 출력
| 출력 | 설명 |
| --- | --- |
| `DISPLAY_COMMAND_UI_STATE_RENDER` | 하위 패널 전체 렌더링 명령 |
## 5. 구현 기준
| 항목 | 기준 |
| --- | --- |
| 후처리 | 상태 전이와 context 갱신이 끝난 뒤 요청한다. |
| payload | 새 패널에 바인딩된 값만 포함한다. |
## 6. 구현 및 검증 상태
| 항목 | 상태 | 날짜 | 비고 |
| --- | --- | --- | --- |
| 구현 | 부분 구현 | - | 공통 전이 후 렌더링 경로는 있으나 하위 패널 상태와 binding이 없다. |
| 검증 | 미완료 | - | 각 하위 패널의 최초 표시값을 검증한다. |
