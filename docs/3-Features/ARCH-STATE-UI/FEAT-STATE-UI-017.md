# FEAT-STATE-UI-017: 상위 패널 선택 context 유지
## 1. 연결된 상위 설계 항목
| 설계 항목 식별자 | 설계 항목 설명 |
| --- | --- |
| `ARCH-STATE-UI-017` | 하위 패널 진입 전 선택했던 상위 패널 context를 복귀 후에도 유지한다. |
## 2. 설명
하위 패널 진입과 Exit 전이 동안 상위 패널의 선택 항목을 초기화하지 않는다.
## 3. 입력
| 입력 | 설명 |
| --- | --- |
| UI 선택 context, Enter·Exit 전이 | 유지 대상과 전이 정보 |
## 4. 출력
| 출력 | 설명 |
| --- | --- |
| 유지된 UI 선택 context | 복귀 후 사용할 선택값 |
## 5. 구현 기준
| 항목 | 기준 |
| --- | --- |
| 보존 | 전이 생명주기에서 parent 선택값을 덮어쓰지 않는다. |
| 독립성 | 서로 다른 상위 패널의 선택값을 구분한다. |
## 6. 구현 및 검증 상태
| 항목 | 상태 | 날짜 | 비고 |
| --- | --- | --- | --- |
| 구현 | 미구현 | - | UI 선택 context가 아직 없다. |
| 검증 | 미완료 | - | 진입 전 선택과 복귀 후 선택이 같은지 검증한다. |
