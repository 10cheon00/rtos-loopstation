# FEAT-STATE-UI-003: 초기 홈 패널 상태
## 1. 연결된 상위 설계 항목
| 설계 항목 식별자 | 설계 항목 설명 |
| --- | --- |
| `ARCH-STATE-UI-003` | UI 상태 머신의 초기 상태를 홈 패널 상태로 등록한다. |
## 2. 설명
UI 상태 머신 시작 시 `UI_STATE_HOME_PANEL`을 현재 상태로 설정하고 `on_enter()`를 호출한다.
## 3. 입력
| 입력 | 설명 |
| --- | --- |
| UI 상태 머신 초기화 | 상태 머신 시작 요청 |
## 4. 출력
| 출력 | 설명 |
| --- | --- |
| `UI_PANEL_ID_HOME` | 초기 current state |
## 5. 구현 기준
| 항목 | 기준 |
| --- | --- |
| 초기 상태 | 다른 이벤트를 처리하기 전에 HOME을 등록한다. |
| 생명주기 | HOME 등록 후 `on_enter()`를 한 번 호출한다. |
## 6. 구현 및 검증 상태
| 항목 | 상태 | 날짜 | 비고 |
| --- | --- | --- | --- |
| 구현 | 완료 | 2026-07-28 | StateTask가 HOME을 current state로 설정하고 `on_enter()`를 호출한다. |
| 검증 | 미완료 | - | 시작 직후 current state를 검증해야 한다. |
