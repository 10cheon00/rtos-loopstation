# FEAT-STATE-UI-019: FX 직접 진입 이벤트 판정
## 1. 연결된 상위 설계 항목
| 설계 항목 식별자 | 설계 항목 설명 |
| --- | --- |
| `ARCH-STATE-UI-019` | IFX·TFX 직접 진입 이벤트를 일반 패널 탐색보다 먼저 검사한다. |
## 2. 설명
현재 패널과 관계없이 IFX·TFX 버튼 이벤트를 전역 UI 전이 대상으로 분류한다.
## 3. 입력
| 입력 | 설명 |
| --- | --- |
| `StateEvent` | IFX 또는 TFX `ControlButtonId`를 가진 버튼 이벤트 |
## 4. 출력
| 출력 | 설명 |
| --- | --- |
| FX 직접 진입 종류 | IFX, TFX 또는 해당 없음 |
## 5. 구현 기준
| 항목 | 기준 |
| --- | --- |
| 우선순위 | 일반 current-state 이벤트 처리보다 먼저 적용한다. |
| 상태 | 유효한 버튼 상태에서만 직접 진입을 발생시킨다. |
## 6. 구현 및 검증 상태
| 항목 | 상태 | 날짜 | 비고 |
| --- | --- | --- | --- |
| 구현 | 미구현 | - | StateTask에 FX 직접 진입 분류가 없다. |
| 검증 | 미완료 | - | 모든 current panel에서 IFX·TFX 입력을 검증한다. |
