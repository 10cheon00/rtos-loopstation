# FEAT-STATE-UI-013: 트랙 하위 패널 전이
## 1. 연결된 상위 설계 항목
| 설계 항목 식별자 | 설계 항목 설명 |
| --- | --- |
| `ARCH-STATE-UI-013` | 선택 트랙을 유지한 채 트랙 설정 패널로 전이한다. |
## 2. 설명
TRACK에서 Enter 이벤트가 발생하면 선택 트랙을 유지하고 `TRACK_SETTING`으로 전이한다.
## 3. 입력
| 입력 | 설명 |
| --- | --- |
| 선택 트랙, Enter 이벤트 | 트랙 설정 진입 정보 |
## 4. 출력
| 출력 | 설명 |
| --- | --- |
| `TRACK_SETTING`, transition flag | 트랙 설정 상태 전이 결과 |
## 5. 구현 기준
| 항목 | 기준 |
| --- | --- |
| 유효성 | 유효한 선택 트랙이 있을 때만 전이한다. |
| context | 선택 트랙 ID를 전이 후에도 유지한다. |
## 6. 구현 및 검증 상태
| 항목 | 상태 | 날짜 | 비고 |
| --- | --- | --- | --- |
| 구현 | 미구현 | - | TRACK 상태와 선택 트랙 context가 없다. |
| 검증 | 미완료 | - | 각 트랙 선택과 무선택 상태를 검증한다. |
