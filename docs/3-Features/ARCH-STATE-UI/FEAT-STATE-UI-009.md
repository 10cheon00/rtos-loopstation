# FEAT-STATE-UI-009: 상위 패널 전이 후 렌더링
## 1. 연결된 상위 설계 항목
| 설계 항목 식별자 | 설계 항목 설명 |
| --- | --- |
| `ARCH-STATE-UI-009` | StateTask가 상위 패널 전이 완료 후 새 패널 렌더링을 요청한다. |
## 2. 설명
StateTask가 상위 패널 전이를 마친 뒤 current panel과 바인딩 파라미터를 표시 명령으로 전송한다.
## 3. 입력
| 입력 | 설명 |
| --- | --- |
| transition flag, current `UiPanelId` | 상태 처리 결과와 전이된 패널 |
## 4. 출력
| 출력 | 설명 |
| --- | --- |
| `DISPLAY_COMMAND_UI_STATE_RENDER` | 새 상위 패널 전체 렌더링 명령 |
## 5. 구현 기준
| 항목 | 기준 |
| --- | --- |
| 후처리 | `StateMachine_DoTransition()` 이후 StateTask가 요청한다. |
| 단일 요청 | 하나의 이벤트마다 렌더링 명령을 최대 한 번 만든다. |
## 6. 구현 및 검증 상태
| 항목 | 상태 | 날짜 | 비고 |
| --- | --- | --- | --- |
| 구현 | 부분 구현 | - | HOME·SETTING 전이 후 공통 렌더링 요청 경로가 구현되어 있다. |
| 검증 | 부분 완료 | 2026-07-28 | 두 패널 전이 경로를 코드로 확인했으며 전체 상위 패널 검증이 남아 있다. |
