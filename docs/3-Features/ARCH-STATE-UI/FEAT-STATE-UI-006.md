# FEAT-STATE-UI-006: 상위 패널 좌 전이
## 1. 연결된 상위 설계 항목
| 설계 항목 식별자 | 설계 항목 설명 |
| --- | --- |
| `ARCH-STATE-UI-006` | 좌 조작을 왼쪽 인접 패널 전이로 변환한다. |
## 2. 설명
좌 버튼 이벤트를 현재 상위 패널의 왼쪽 인접 상태 전이로 처리한다.
## 3. 입력
| 입력 | 설명 |
| --- | --- |
| `STATE_EVENT_CONTROL_BUTTON`, 현재 `UiPanelId` | 좌 버튼 release와 현재 패널 |
## 4. 출력
| 출력 | 설명 |
| --- | --- |
| 다음 `StateId`, transition flag | 왼쪽 목적 상태와 처리 결과 |
## 5. 구현 기준
| 항목 | 기준 |
| --- | --- |
| 전이 | HOME->SETTING, FX->HOME, TRACK->FX를 지원한다. |
| 의미 제한 | UI 상태는 다음 ID만 반환하고 직접 current state를 바꾸지 않는다. |
## 6. 구현 및 검증 상태
| 항목 | 상태 | 날짜 | 비고 |
| --- | --- | --- | --- |
| 구현 | 부분 구현 | - | HOME->SETTING만 구현되어 있다. |
| 검증 | 미완료 | - | 세 좌 전이를 검증해야 한다. |
