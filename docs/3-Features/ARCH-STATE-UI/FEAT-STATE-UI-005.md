# FEAT-STATE-UI-005: 상위 패널 탐색 순서
## 1. 연결된 상위 설계 항목
| 설계 항목 식별자 | 설계 항목 설명 |
| --- | --- |
| `ARCH-STATE-UI-005` | 상위 패널의 좌우 인접 관계를 정적 탐색표로 정의한다. |
## 2. 설명
`SETTING`, `HOME`, `FX`, `TRACK`의 비순환 인접 관계를 정적으로 정의한다.
## 3. 입력
| 입력 | 설명 |
| --- | --- |
| 현재 상위 `UiPanelId`, 방향 | 탐색 시작 패널과 좌우 방향 |
## 4. 출력
| 출력 | 설명 |
| --- | --- |
| 인접 `UiPanelId` | 존재하는 경우의 목적 패널 |
## 5. 구현 기준
| 항목 | 기준 |
| --- | --- |
| 순서 | `SETTING <-> HOME <-> FX <-> TRACK`을 유지한다. |
| 비순환 | 양 끝 패널을 서로 연결하지 않는다. |
## 6. 구현 및 검증 상태
| 항목 | 상태 | 날짜 | 비고 |
| --- | --- | --- | --- |
| 구현 | 부분 구현 | - | HOME과 SETTING의 일부 관계만 상태 함수에 하드코딩되어 있다. |
| 검증 | 미완료 | - | 모든 상위 패널과 양방향 관계를 검증한다. |
