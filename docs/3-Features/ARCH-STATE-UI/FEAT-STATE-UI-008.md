# FEAT-STATE-UI-008: 상위 패널 탐색 경계
## 1. 연결된 상위 설계 항목
| 설계 항목 식별자 | 설계 항목 설명 |
| --- | --- |
| `ARCH-STATE-UI-008` | 목록 경계 밖 조작은 처리하되 현재 상태를 유지한다. |
## 2. 설명
SETTING의 좌 조작과 TRACK의 우 조작에서 유효 상태를 유지하고 경계 입력으로 처리한다.
## 3. 입력
| 입력 | 설명 |
| --- | --- |
| 경계 패널의 바깥 방향 이벤트 | SETTING+LEFT 또는 TRACK+RIGHT |
## 4. 출력
| 출력 | 설명 |
| --- | --- |
| 상태 유지 처리 결과 | transition 없는 handled 결과 |
## 5. 구현 기준
| 항목 | 기준 |
| --- | --- |
| 상태 보존 | current state와 context를 변경하지 않는다. |
| 결과 | 미지원 오류가 아닌 정상 경계 입력으로 구분한다. |
## 6. 구현 및 검증 상태
| 항목 | 상태 | 날짜 | 비고 |
| --- | --- | --- | --- |
| 구현 | 미구현 | - | 현재는 경계 입력을 `IGNORED`로 반환하며 handled 결과가 없다. |
| 검증 | 미완료 | - | 양 끝 패널의 상태 보존을 검증한다. |
