# FEAT-STATE-UI-011: 설정 하위 패널 전이
## 1. 연결된 상위 설계 항목
| 설계 항목 식별자 | 설계 항목 설명 |
| --- | --- |
| `ARCH-STATE-UI-011` | 설정 선택에 따라 시스템 설정 또는 하드웨어 점검 패널로 전이한다. |
## 2. 설명
SETTING의 선택 항목을 `SYSTEM_SETTING` 또는 `HARDWARE_DIAGNOSTIC` 상태로 변환한다.
## 3. 입력
| 입력 | 설명 |
| --- | --- |
| SETTING 선택 항목, Enter 이벤트 | 하위 패널 결정 정보 |
## 4. 출력
| 출력 | 설명 |
| --- | --- |
| 목적 `StateId`, transition flag | 선택된 설정 하위 상태 |
## 5. 구현 기준
| 항목 | 기준 |
| --- | --- |
| 매핑 | 각 지원 설정 항목에 정확히 하나의 하위 패널을 연결한다. |
| 무효 선택 | 현재 상태를 훼손하지 않고 오류 또는 rejected로 구분한다. |
## 6. 구현 및 검증 상태
| 항목 | 상태 | 날짜 | 비고 |
| --- | --- | --- | --- |
| 구현 | 미구현 | - | 하위 설정 상태와 Enter 전이가 없다. |
| 검증 | 미완료 | - | 모든 설정 항목 매핑을 검증한다. |
