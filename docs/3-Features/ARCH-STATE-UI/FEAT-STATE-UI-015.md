# FEAT-STATE-UI-015: 하위 패널 parent 매핑
## 1. 연결된 상위 설계 항목
| 설계 항목 식별자 | 설계 항목 설명 |
| --- | --- |
| `ARCH-STATE-UI-015` | 하위 패널별 parent 패널을 정적 관계로 정의한다. |
## 2. 설명
각 하위 `UiPanelId`를 Exit 시 복귀할 상위 `UiPanelId`에 연결한다.
## 3. 입력
| 입력 | 설명 |
| --- | --- |
| 하위 `UiPanelId` | 현재 하위 패널 |
## 4. 출력
| 출력 | 설명 |
| --- | --- |
| parent `UiPanelId` | Exit 목적 상위 패널 |
## 5. 구현 기준
| 항목 | 기준 |
| --- | --- |
| 완전성 | 모든 하위 패널에 정확히 하나의 parent를 정의한다. |
| 정적 설정 | 상태 처리 코드에 parent ID를 반복 하드코딩하지 않는다. |
## 6. 구현 및 검증 상태
| 항목 | 상태 | 날짜 | 비고 |
| --- | --- | --- | --- |
| 구현 | 미구현 | - | 하위 패널과 parent 매핑이 없다. |
| 검증 | 미완료 | - | 모든 하위 패널의 parent를 검증한다. |
