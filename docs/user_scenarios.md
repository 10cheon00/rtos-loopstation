# 사용자 시나리오

## 1. 기본 전원 인가 및 시작

1. 사용자가 시스템 전원을 인가한다.
2. 시스템은 MCU와 peripheral을 초기화한다.
3. 시스템은 RTOS 자원을 초기화한다.
4. 시스템은 SD 카드를 마운트한다.
5. 시스템은 FX 처리 자원을 준비한다.
6. 시스템은 루프스테이션 동작을 시작한다.
7. LCD는 홈 패널을 표시한다.

## 2. 오디오 passthrough 확인

1. 사용자가 INMP441 마이크와 DAC 출력을 연결한다.
2. 시스템은 `SAI1 Block B`로 마이크 데이터를 수신한다.
3. 시스템은 수신한 오디오 데이터를 `SAI1 Block A`로 DAC에 출력한다.
4. 사용자는 출력 장치에서 입력음이 들리는지 확인한다.

현재 검증 상태:

- INMP441 입력을 UDA1334A 출력으로 passthrough 가능함을 확인했다.
- INMP441 입력을 PCM5102A 출력으로 passthrough 가능함을 확인했다. PCM5102A는 `XSMT`를 3.3 V에 연결했을 때 출력 가능함을 확인했다.

## 3. 첫 녹음

초기 상태:

- 시스템은 `RUNNING` 상태다.
- 대상 트랙은 `IDLE` 상태다.

흐름:

1. 사용자가 녹음/재생 버튼을 누른다.
2. 트랙 상태가 `IDLE`에서 `RECORDING`으로 전환된다.
3. 오디오 처리 태스크는 입력 오디오를 수신한다.
4. 필요한 경우 오디오 처리 태스크는 IFX를 입력 오디오에 적용한다.
5. 저장 장치 입출력 태스크는 오디오 데이터를 저장한다.
6. 사용자가 녹음/재생 버튼을 다시 누른다.
7. 트랙 상태가 `RECORDING`에서 `PLAYING`으로 전환된다.
8. 저장된 트랙이 반복 재생된다.

## 4. 녹음 정지

초기 상태:

- 대상 트랙은 `RECORDING` 상태다.

흐름:

1. 사용자가 정지 버튼을 누른다.
2. 저장 장치 입출력 태스크는 오디오 데이터를 저장한다.
3. 트랙 상태가 `RECORDING`에서 `STOPPED`으로 전환된다.

## 5. 반복 재생

초기 상태:

- 대상 트랙은 녹음 데이터를 가지고 있다.
- 대상 트랙은 `PLAYING` 또는 `STOPPED` 상태가 될 수 있다.

흐름:

1. `PLAYING` 상태에서는 저장된 트랙이 반복 재생된다.
2. `STOPPED` 상태에서 사용자가 녹음/재생 버튼을 누르면 `PLAYING`으로 전환된다.
3. 저장 장치 입출력 태스크는 오디오 처리 태스크에게 트랙 오디오 데이터를 처음 위치부터 스트리밍한다.
4. 필요한 경우 오디오 처리 태스크는 TFX를 출력 오디오에 적용한다.
5. 오디오 처리 태스크는 출력 장치로 오디오 데이터를 출력한다.
6. 저장 장치 입출력 태스크가 트랙 오디오 데이터를 끝까지 읽었다면 다시 처음 위치로 돌아가 스트리밍을 재개한다.
7. 재생 중 사용자가 정지 버튼을 누르면 `STOPPED`로 전환된다.

## 6. 오버더빙

초기 상태:

- 대상 트랙은 `PLAYING` 상태다.

흐름:

1. 사용자가 녹음/재생 버튼을 누른다.
2. 트랙 상태가 `PLAYING`에서 `OVERDUBBING`으로 전환된다.
3. 시스템은 기존 트랙을 반복 재생하면서 새 입력 오디오를 기존 오디오와 합친다.
4. 사용자가 녹음/재생 버튼을 다시 누른다.
5. 트랙 상태가 `OVERDUBBING`에서 `PLAYING`으로 전환된다.
6. 트랙은 현재 재생 위치를 유지하며 반복 재생을 계속한다.

## 7. 트랙 삭제

초기 상태:

- 대상 트랙은 `STOPPED` 상태다.

흐름:

1. 사용자가 정지 버튼을 길게 누르거나 짧은 시간 안에 연속으로 누른다.
2. 시스템은 트랙의 저장 데이터를 삭제한다.
3. 트랙 상태가 `IDLE`로 전환된다.

## 8. FX 조작

흐름:

1. 사용자가 IFX 또는 TFX 버튼을 누른다.
2. 해당 FX 활성화 상태가 토글된다.
3. LCD는 IFX/TFX 설정 패널로 전환된다.
4. 사용자가 노브 또는 엔코더로 FX 파라미터를 조절한다.
5. 시스템은 입력 또는 출력 오디오에 해당 FX를 적용한다.

FX별 파라미터와 노브 조작 대상은 [fx_design.md](./fx_design.md)를 기준으로 한다.

## 9. UI 탐색

흐름:

1. 시스템은 전원 인가 후 홈 패널을 표시한다.
2. 사용자는 좌우 버튼으로 같은 계층의 패널을 이동한다.
3. 사용자는 Enter 버튼으로 하위 패널에 진입한다.
4. 사용자는 Exit 버튼으로 상위 패널로 이동한다.

패널 계층은 [ui_design.md](./ui_design.md)를 따른다.
