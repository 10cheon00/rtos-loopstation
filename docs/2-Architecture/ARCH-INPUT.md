# 사용자 입력 아키텍처 간소화 초안

이 문서는 `ARCH-INPUT.md`를 대체하기 전에 검토할 간소화 양식의 예시다.
기존의 아키텍처 항목, 역할, 설계 결정은 `설계 설명`으로 합치고 공통 설계를 요구사항별 설계보다 먼저 제시한다.
각 기능 ID는 `3-Features`의 기능 명세를 거쳐 상세 구현 문서와 실제 코드로 이어진다.
입력 구조의 책임은 물리 조작을 식별자, 상태, 값이 포함된 이벤트로 변환해 상태 관리 구조에 전달하는 시점에 끝난다.
상태 관리 구조가 이벤트를 어떻게 판단하고 어떤 동작을 수행하는지는 이 문서에서 다루지 않는다.

## 1. 공통 설계

| 설계 ID | 설계 설명 | 입력 | 출력 | 적용 요구사항 |
| --- | --- | --- | --- | --- |
| `ARCH-INPUT-031` | 버튼의 접점 흔들림을 제거하고 안정된 눌림/떼짐 이벤트를 만든다. | 버튼의 전기적 상태 | 버튼 식별자와 눌림/떼짐 상태 (`CONTROL_BUTTON`) | `REQ-INPUT-001`, `REQ-INPUT-002`, `REQ-INPUT-006` |
| `ARCH-INPUT-032` | 접점 흔들림 제거가 끝난 버튼 상태를 보관하고 엔코더 회전 시점에 복사한다. | 안정된 버튼 상태 | 회전 시점에 눌린 보조 버튼 정보 (`modifier_mask`) | `REQ-INPUT-005`, `REQ-INPUT-006` |
| `ARCH-INPUT-033` | 아날로그 값을 주기적으로 읽고 최소 변화량과 전송 주기를 적용해 의미 있는 변경만 만든다. | 아날로그 원시값 | 조작기 식별자와 변경값 (`CONTROL_POT_CHANGE`) | `REQ-INPUT-003`, `REQ-INPUT-004` |
| `ARCH-INPUT-034` | 엔코더 회전 방향과 이동량을 계산해 하나의 회전 이벤트로 만든다. | 엔코더 회전 신호 | 엔코더 식별자와 회전 방향·이동량 (`CONTROL_ENCODER_ROTATE`) | `REQ-INPUT-005` |
| `ARCH-INPUT-035` | 변환된 입력 이벤트를 발생 순서대로 상태 관리 구조에 전달한다. | 변환이 끝난 입력 이벤트 | 상태 관리 큐에 저장된 입력 이벤트 (`state_event_queue`) | `REQ-INPUT-001` ~ `REQ-INPUT-006` |

## 2. 요구사항별 설계

### 2.1 REQ-INPUT-001

제어부의 좌, 우, Enter, Exit 조작을 버튼 식별자와 눌림/떼짐 상태가 포함된 이벤트로 변환한다.

| 설계 ID | 설계 설명 | 입력 | 출력 |
| --- | --- | --- | --- |
| `ARCH-INPUT-001` | 좌, 우, Enter, Exit 버튼의 물리 상태를 읽는다. | 버튼의 전기적 신호 | 가공 전 버튼 상태 |
| `ARCH-INPUT-002` | 접점 흔들림을 제거하고 안정된 눌림/떼짐 변화를 확정한다. | 가공 전 버튼 상태 | 안정된 버튼 상태 변화 |
| `ARCH-INPUT-003` | 버튼 식별자, 상태, 감지 시각을 하나의 이벤트로 만든다. | 안정된 버튼 상태 변화, 버튼 식별자, 감지 시각 | 버튼 식별자와 눌림/떼짐 이벤트 (`CONTROL_BUTTON`) |

#### 개발 기능

| 기능 ID | 기능 목적 |
| --- | --- |
| `FEAT-INPUT-001` ~ `FEAT-INPUT-009` | 버튼 인터럽트 기록부터 버튼 식별자와 눌림/떼짐 이벤트 전송, 오류 기록까지 구현한다. |

### 2.2 REQ-INPUT-002

FX부의 IFX/TFX 조작을 버튼 식별자와 눌림/떼짐 상태가 포함된 이벤트로 변환한다.

| 설계 ID | 설계 설명 | 입력 | 출력 |
| --- | --- | --- | --- |
| `ARCH-INPUT-006` | IFX/TFX 버튼의 상태 변화를 공통 버튼 입력 경로로 감지한다. | IFX/TFX 버튼의 전기적 신호 | 안정된 버튼 상태 변화 |
| `ARCH-INPUT-007` | FX 버튼 식별자와 상태를 하나의 이벤트로 만든다. | 안정된 버튼 상태 변화, FX 버튼 식별자 | FX 버튼 식별자와 눌림/떼짐 이벤트 (`CONTROL_BUTTON`) |

#### 개발 기능

| 기능 ID | 기능 목적 |
| --- | --- |
| `FEAT-INPUT-001` ~ `FEAT-INPUT-009` | FX 버튼 조작을 버튼 식별자와 눌림/떼짐 이벤트로 만들어 전달한다. |

### 2.3 REQ-INPUT-003

FX부의 아날로그 조작을 조작기 식별자와 값이 포함된 이벤트로 변환한다.

| 설계 ID | 설계 설명 | 입력 | 출력 |
| --- | --- | --- | --- |
| `ARCH-INPUT-011` | FX부 아날로그 조작값을 정해진 주기로 읽는다. | FX부 아날로그 전압 또는 변환값 | 아날로그 원시값 |
| `ARCH-INPUT-012` | 최소 변화량과 전송 주기를 적용해 의미 없는 미세 변화와 과도한 이벤트를 제거한다. | 현재 원시값과 직전 원시값 | 의미 있는 아날로그 변경값 |
| `ARCH-INPUT-013` | 원시값을 후속 구조가 공통으로 사용할 수 있는 범위로 정규화한다. | 의미 있는 아날로그 변경값 | 원시값과 정규화된 값 |
| `ARCH-INPUT-014` | 조작기 식별자와 값을 하나의 이벤트로 만든다. | 조작기 식별자, 원시값, 정규화된 값 | 조작기 식별자와 변경값 이벤트 (`CONTROL_POT_CHANGE`) |

#### 개발 기능

| 기능 ID | 기능 목적 |
| --- | --- |
| `FEAT-INPUT-010`, `FEAT-INPUT-012` ~ `FEAT-INPUT-014` | FX부 아날로그 값을 샘플링하고 의미 변화 판정과 정규화를 거쳐 조작기 변경 이벤트로 만든다. |

### 2.4 REQ-INPUT-004

트랙부의 아날로그 조작을 조작기 식별자와 값이 포함된 이벤트로 변환한다.

| 설계 ID | 설계 설명 | 입력 | 출력 |
| --- | --- | --- | --- |
| `ARCH-INPUT-016` | 트랙부 아날로그 조작값을 공통 아날로그 입력 경로로 읽는다. | 트랙부 아날로그 전압 또는 변환값 | 아날로그 원시값 |
| `ARCH-INPUT-018` | 원시값을 후속 구조가 공통으로 사용할 수 있는 범위로 정규화한다. | 아날로그 원시값 | 정규화된 값 |

#### 개발 기능

| 기능 ID | 기능 목적 |
| --- | --- |
| `FEAT-INPUT-010`, `FEAT-INPUT-012` ~ `FEAT-INPUT-014` | 트랙부 아날로그 값을 샘플링하고 의미 변화 판정과 정규화를 거쳐 조작기 변경 이벤트로 만든다. |

### 2.5 REQ-INPUT-005

로터리 조작을 엔코더 식별자와 회전 방향·이동량이 포함된 이벤트로 변환한다.

| 설계 ID | 설계 설명 | 입력 | 출력 |
| --- | --- | --- | --- |
| `ARCH-INPUT-020` | 엔코더 입력에서 회전 방향과 이동한 칸 수를 계산한다. | 엔코더 계수기 값 변화 또는 두 회전 신호 | 회전 방향과 이동한 칸 수 |
| `ARCH-INPUT-021` | 시계 방향은 양수, 반시계 방향은 음수인 변화량으로 변환한다. | 회전 방향과 이동한 칸 수 | 부호가 있는 회전 변화량 |
| `ARCH-INPUT-022` | 접점 흔들림 제거가 끝난 버튼별 눌림/떼짐 상태를 보관한다. | 안정된 버튼 상태 | 현재 버튼 상태 모음 (`button_state_snapshot`) |
| `ARCH-INPUT-023` | 회전 시점에 눌린 보조 버튼 상태를 현재 버튼 상태 모음에서 복사한다. | 현재 버튼 상태 모음 | 회전 시점의 보조 버튼 정보 (`modifier_mask`) |
| `ARCH-INPUT-024` | 엔코더 식별자, 회전 변화량, 이동한 칸 수, 보조 버튼 상태와 감지 시각을 하나의 이벤트로 만든다. | 엔코더 식별자, 회전값, 보조 버튼 상태, 감지 시각 | 엔코더 회전 이벤트 (`CONTROL_ENCODER_ROTATE`) |

#### 개발 기능

| 기능 ID | 기능 목적 |
| --- | --- |
| `FEAT-INPUT-011`, `FEAT-INPUT-015` ~ `FEAT-INPUT-017` | 로터리 인터럽트를 기록하고 signed delta와 보조 버튼 상태가 포함된 회전 이벤트로 만든다. |

### 2.6 REQ-INPUT-006

로터리 누름 조작을 버튼 식별자와 눌림/떼짐 상태가 포함된 이벤트로 변환하고 현재 상태를 보관한다.

| 설계 ID | 설계 설명 | 입력 | 출력 |
| --- | --- | --- | --- |
| `ARCH-INPUT-026` | 엔코더 누름 버튼 상태를 공통 버튼 입력 경로로 읽는다. | 엔코더 누름 버튼의 전기적 신호 | 안정된 버튼 상태 변화 |
| `ARCH-INPUT-027` | 확정된 엔코더 누름 상태를 현재 버튼 상태 모음에 반영한다. | 안정된 엔코더 누름 상태 | 현재 엔코더 누름 상태 |
| `ARCH-INPUT-028` | 엔코더 누름 버튼 식별자와 상태를 하나의 이벤트로 만든다. | 안정된 엔코더 누름 상태, 감지 시각 | 엔코더 누름 버튼 이벤트 (`CONTROL_BUTTON`) |
| `ARCH-INPUT-030` | 현재 엔코더 누름 상태를 회전 이벤트의 보조 버튼 정보로 제공한다. | 현재 엔코더 누름 상태 | 회전 시점의 보조 버튼 정보 (`modifier_mask`) |

#### 개발 기능

| 기능 ID | 기능 목적 |
| --- | --- |
| `FEAT-INPUT-001` ~ `FEAT-INPUT-009` | 엔코더 누름 버튼의 인터럽트, 접점 흔들림 제거, 현재 상태 갱신과 버튼 이벤트 전송을 구현한다. |
