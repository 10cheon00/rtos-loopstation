# 테스트 계획

## 1. 테스트 목적

이 문서는 개발 과정에서의 Loop Station 프로젝트의 하드웨어 bring-up, peripheral 단독 테스트, 통합 기능 테스트 항목을 정의한다.

## 2. 테스트 단계

| 단계 | 목적 |
| --- | --- |
| 1. 모듈 단독 테스트 | 각 peripheral과 모듈이 독립적으로 동작하는지 확인 |
| 2. 하드웨어 통합 테스트 | 여러 모듈을 동시에 연결했을 때 충돌 없이 동작하는지 확인 |
| 3. 오디오 경로 테스트 | 입력, 출력, passthrough, 녹음, 재생 경로 확인 |
| 4. UI/상태 테스트 | 버튼, 엔코더, LCD, LED, 상태 머신 동작 확인 |
| 5. 저장장치 테스트 | SD 카드 파일 입출력과 트랙 데이터 저장/읽기 확인 |

## 5. 상태 머신 테스트

| --- | --- | --- |
