# 루프스테이션 요구사항 정의서

이 문서는 루프스테이션 시스템이 외부에서 관찰 가능한 수준에서 어떻게 동작해야 하는지 정의한다.
구체적인 하드웨어 모듈, peripheral, 태스크, 함수, 버퍼 구조 등 구현 방식은 이 문서가 아니라 설계 문서와 기능 문서에서 다룬다.

## 1. 작성 기준

- 요구사항은 시스템이 제공해야 하는 동작과 제약을 기술한다.
- 특정 부품명, peripheral명, 핀명, 태스크명, 함수명은 요구사항 본문에 직접 적지 않는다.
- 구현 방법이 아니라 사용자가 관찰할 수 있는 결과와 시스템이 만족해야 하는 조건을 중심으로 작성한다.
- 각 요구사항은 설계 문서와 기능 문서로 추적 가능해야 한다.
- 검증 기준은 시험, 확인, 분석, 시연 중 하나 이상의 방식으로 확인 가능하게 작성한다.

| REQ-FX | 오디오 효과 | 입력 또는 트랙 오디오에 적용되는 효과 처리 동작 | [ARCH-FX.md](../2-Architecture/ARCH-FX.md) |
| REQ-TRACK | 트랙 생명주기 | 녹음, 재생, 오버더빙, 초기화 등 트랙 상태 변화 | [ARCH-TRACK.md](../2-Architecture/ARCH-TRACK.md) |
