# 프로젝트 기획서

## 1. 프로젝트 개요

Loop Station 프로젝트는 임베디드 환경에서 동작하는 루프스테이션 시스템을 직접 설계하고 구현하는 프로젝트다. 시스템은 실시간으로 음성 또는 외부 오디오 신호를 받아 트랙으로 저장하고, 저장된 트랙을 반복 재생하며, 재생 중인 트랙 위에 새로운 오디오 신호를 추가할 수 있어야 한다.

이 프로젝트는 소프트웨어뿐 아니라 입력 장치, 디스플레이, 저장장치, 오디오 입출력 회로를 포함한 하드웨어 구성을 함께 다룬다.

## 2. 프로젝트 목표

- 실시간 오디오 입력을 받아 출력 장치로 내보낼 수 있다.
- 입력 오디오를 트랙으로 녹음하고 저장할 수 있다.
- 저장된 트랙을 반복 재생할 수 있다.
- 재생 중인 트랙에 오버더빙할 수 있다.
- LCD, 버튼, 로터리 엔코더, LED를 통해 시스템 상태를 확인하고 조작할 수 있다.
- 입력 FX와 출력 FX를 적용할 수 있는 구조를 마련한다.

## 3. MVP 범위

프로토타입 기준으로 다음 범위를 우선 구현한다.

| 구분 | MVP 범위 |
| --- | --- |
| 트랙 수 | 1개 |
| 입력 | INMP441 I2S 마이크 |
| 출력 | UDA1334A 또는 PCM5102A I2S DAC |
| 저장장치 | SD 카드 + FatFs |
| 표시장치 | GMG12864-06D LCD |
| 조작장치 | MCP23017 기반 버튼, KY-040 로터리 엔코더, 포텐셔미터 |
| FX | IFX 1개, TFX 1개 |
| FX 후보 | LPF, HPF, EQ, Reverb |

## 6. 핵심 기능

| 기능 | 설명 |
| --- | --- |
| 오디오 passthrough | INMP441에서 들어온 오디오 데이터를 SAI1을 통해 DAC로 출력한다. |
| 트랙 녹음 | 오디오 입력을 트랙 데이터로 저장한다. |
| 반복 재생 | 저장된 트랙을 반복 재생한다. |
| 오버더빙 | 반복 재생 중인 트랙 위에 새 오디오를 추가한다. |
| FX 적용 | 입력 또는 출력 오디오에 FX를 적용한다. |
| UI 표시 | LCD와 LED로 시스템 상태를 표시한다. |
| 사용자 입력 | 버튼, 엔코더, 포텐셔미터로 시스템을 조작한다. |
| 파일 저장 | SD 카드와 FatFs로 트랙 파일을 저장하고 읽는다. |

## 7. 성공 기준

| 단계 | 성공 기준 |
| --- | --- |
| 하드웨어 bring-up | LCD, 버튼/LED 확장, ADC, SD, 엔코더, 오디오 입출력이 각각 단독 테스트를 통과한다. |
| 오디오 입출력 | INMP441 입력을 DAC로 passthrough할 수 있다. |
| 저장장치 | SD 카드 마운트와 파일 입출력이 가능하다. |
| 트랙 상태 | `IDLE`, `RECORDING`, `PLAYING`, `OVERDUBBING`, `STOPPED` 상태 전이가 동작한다. |
| UI | LCD와 LED가 현재 시스템 상태를 사용자가 이해할 수 있게 표시한다. |
