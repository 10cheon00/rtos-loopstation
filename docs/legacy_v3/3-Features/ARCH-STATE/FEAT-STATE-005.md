# 초기 상태 주입

## 1. 기능 범위

| 항목 | 내용 |
| --- | --- |
| 기능 ID | `FEAT-STATE-005` |
| 상위 설계 문서 | `ARCH-STATE.md` |
| 관련 설계 항목 | `ARCH-STATE-005` |
| 관련 요구사항 | `REQ-STATE-002` |
| 주요 목적 | 상태 머신 전용 설계가 정한 초기 상태와 context를 공통 인스턴스에 안전하게 주입한다. |
| 제외 범위 | 초기 상태의 on_enter 실행과 도메인별 초기 상태 선정 |

## 2. 연결된 상위 설계 항목

| 설계 항목 ID | 설계 항목 | 연결 내용 |
| --- | --- | --- |
| `ARCH-STATE-005` | 초기 상태 주입 | 상태 머신 전용 설계가 정한 초기 상태와 context를 공통 인스턴스에 안전하게 주입한다. |

## 3. 목적

상태 머신 전용 설계가 정한 초기 상태와 context를 공통 인스턴스에 안전하게 주입한다.

## 4. 입력

| 입력 | 설명 |
| --- | --- |
| 등록 정보 | 초기 상태, context와 허용 상태 집합 |
| 인스턴스 저장 공간 | 초기화할 대상 |

## 5. 출력

| 출력 | 설명 |
| --- | --- |
| 초기화된 인스턴스 | 초기 상태를 가리키는 상태 머신 |
| 초기화 결과 | 성공 또는 실패 원인 |

## 6. 구현 기준

| 항목 | 기준 |
| --- | --- |
| 소속 검증 | 초기 상태는 허용 상태 집합에 포함되어야 한다. |
| context 검증 | 필수 context 참조를 검사한다. |
| 재초기화 방지 | 실행 중 인스턴스의 무단 초기화를 거부한다. |
| 부분 초기화 방지 | 실패한 인스턴스를 실행 가능 상태로 두지 않는다. |

## 7. 완료 기준

| 기준 | 확인 방법 |
| --- | --- |
| 정상 주입 | 초기 상태와 context가 정확히 반영되는지 확인한다. |
| 소속 오류 | 다른 머신 상태 주입이 실패하는지 확인한다. |
| 부분 실패 | 잘못된 context에서 활성화되지 않는지 확인한다. |
