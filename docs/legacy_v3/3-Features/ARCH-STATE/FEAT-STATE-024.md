# 상태 머신별 초기화 인자 전달

## 1. 기능 범위

| 항목 | 내용 |
| --- | --- |
| 기능 ID | `FEAT-STATE-024` |
| 상위 설계 문서 | `ARCH-STATE.md` |
| 관련 설계 항목 | `ARCH-STATE-024` |
| 관련 요구사항 | `REQ-STATE-002` |
| 주요 목적 | 상태 관리 태스크 초기화 시 전용 자원이 필요한 상태 머신에만 해당 인자를 전달한다. |
| 제외 범위 | 상태 머신 내부 context 구성과 자원의 런타임 사용 |

## 2. 연결된 상위 설계 항목

| 설계 항목 ID | 설계 항목 | 연결 내용 |
| --- | --- | --- |
| `ARCH-STATE-024` | 상태 머신별 인자 전달 | 상위 인자와 태스크 의존성을 검증하고 각 상태 머신에 전용 인자만 전달한다. |

## 3. 목적

상태 관리 태스크가 상태 머신의 구체 자원을 직접 사용하지 않고, 초기화 경로에서 유효성을 확인한 뒤 필요한 전용 인자를 해당 상태 머신에 전달한다.
UI 상태 머신처럼 전용 자원이 없는 인스턴스에는 초기 상태만 등록하고 별도의 InitParams를 전달하지 않는다.

## 4. 입력

| 입력 | 설명 |
| --- | --- |
| `StateInitParams` | 외부 조립 지점이 구성한 전체 초기화 인자 |
| 상태 머신 인스턴스 | 시스템, 트랙, UI 상태 머신 저장 공간 |
| 상태 머신 초기화 함수 | 머신별 InitParams를 받는 초기화 API |

## 5. 출력

| 출력 | 설명 |
| --- | --- |
| 머신별 초기화 결과 | 성공 또는 머신별 실패 원인 |
| 이벤트 처리 가능 여부 | 모든 필수 머신 초기화 완료 여부 |

## 6. 구현 기준

| 항목 | 기준 |
| --- | --- |
| 상위 인자 검증 | `StateInitParams` 포인터와 태스크 필수 자원을 먼저 검증한다. |
| 전용 전달 | 각 머신 초기화 함수에 해당 머신의 InitParams 참조만 전달한다. |
| 선택적 전달 | 전용 자원이 없는 UI 상태 머신에는 불필요한 InitParams나 빈 context를 만들지 않는다. |
| 사용 제한 | 상태 관리 태스크는 머신별 InitParams의 queue, semaphore 및 command port를 이벤트 루프에서 직접 사용하지 않는다. |
| 실패 처리 | 필수 상태 머신 하나라도 초기화에 실패하면 queue 이벤트 처리를 시작하지 않는다. |
| 순서 | 머신별 초기화와 등록을 완료한 뒤 최초 `on_enter`를 실행한다. |

## 7. 완료 기준

| 기준 | 확인 방법 |
| --- | --- |
| 인자 격리 | 각 초기화 함수에 해당 머신의 InitParams만 전달되는지 확인한다. |
| UI 초기화 | UI 상태 머신이 전용 InitParams 없이 초기 상태를 등록할 수 있는지 확인한다. |
| 직접 사용 금지 | 상태 태스크 이벤트 루프가 머신 전용 자원을 참조하지 않는지 확인한다. |
| 실패 차단 | 머신별 초기화 실패 시 이벤트가 dequeue되지 않는지 확인한다. |
