# FX 직접 진입 이벤트

## 1. 기능 범위

| 항목 | 내용 |
| --- | --- |
| 기능 ID | `FEAT-STATE-UI-019` |
| 상위 설계 문서 | `ARCH-STATE-UI.md` |
| 관련 설계 항목 | `ARCH-STATE-UI-019` |
| 관련 요구사항 | `REQ-STATE-UI-012, REQ-STATE-UI-013` |
| 주요 목적 | 현재 패널과 관계없이 FX 설정 패널 이동을 요청한다. |
| 제외 범위 | FX 활성화 toggle과 오디오 command |

## 2. 연결된 상위 설계 항목

| 설계 항목 ID | 설계 항목 | 연결 내용 |
| --- | --- | --- |
| `ARCH-STATE-UI-019` | FX 직접 진입 이벤트 | IFX와 TFX 조작 이벤트를 공통 패널 전이표보다 먼저 검사한다. |

## 3. 목적

현재 패널과 관계없이 FX 설정 패널 이동을 요청한다.
이를 위해 IFX와 TFX 조작 이벤트를 공통 패널 전이표보다 먼저 검사한다.

## 4. 입력

| 입력 | 설명 |
| --- | --- |
| 현재 UI panel | 상위 또는 하위 상태 |
| FX 직접 조작 이벤트 | IFX 또는 TFX |

## 5. 출력

| 출력 | 설명 |
| --- | --- |
| 직접 진입 판정 | 일반 panel 전이보다 우선하는 목적 state |

## 6. 구현 기준

| 항목 | 기준 |
| --- | --- |
| 설계 결정 | IFX와 TFX 조작 이벤트를 공통 패널 전이표보다 먼저 검사한다. |
| 우선순위 | 직접 진입 이벤트를 일반 좌우 및 Enter 전이표보다 먼저 판정해야 한다. |
| 오류 처리 | 입력, panel state 또는 context가 유효하지 않으면 canonical panel state를 변경하지 않고 명시적 오류 또는 거부 결과를 반환해야 한다. |
| 실행 문맥 | 상태 관리 태스크의 이벤트 처리 경로에서 동적 메모리 할당과 무제한 blocking 없이 실행해야 한다. |

## 7. 완료 기준

| 기준 | 확인 방법 |
| --- | --- |
| 전역 이벤트 | 서로 다른 current panel에서 같은 FX 직접 목적지가 선택되는지 확인한다. |
| 오류 경로 | 잘못된 입력에서 panel state와 유효한 context가 훼손되지 않는지 확인한다. |
| 설계 추적 | 구현과 시험이 `ARCH-STATE-UI-019`의 설계 결정을 만족하는지 검토한다. |
