# 프로젝트 기획서

## 1. 프로젝트 개요

Loop Station 프로젝트는 임베디드 환경에서 동작하는 루프스테이션 시스템을 직접 설계하고 구현하는 프로젝트다. 시스템은 실시간으로 음성 또는 외부 오디오 신호를 받아 트랙으로 저장하고, 저장된 트랙을 반복 재생하며, 재생 중인 트랙 위에 새로운 오디오 신호를 추가할 수 있어야 한다.

이 프로젝트는 소프트웨어뿐 아니라 입력 장치, 디스플레이, 저장장치, 오디오 입출력 회로를 포함한 하드웨어 구성을 함께 다룬다.

구현해야할 루프스테이션의 기능들은 RC-505 MK1을 참고하였다.

## 2. 프로젝트 목표

- 실시간 오디오 입력을 받아 출력 장치로 내보낼 수 있다.
- 입력 오디오를 트랙으로 녹음하고 저장할 수 있다.
- 저장된 트랙을 반복 재생할 수 있다.
- 재생 중인 트랙에 오버더빙할 수 있다.
- LCD, 버튼, 로터리 엔코더, LED를 통해 시스템 상태를 확인하고 조작할 수 있다.
- 입력 FX와 출력 FX를 적용할 수 있는 구조를 마련한다.

## 3. MVP 범위

프로토타입 기준으로 다음 범위를 우선 구현한다.

| 구분 | MVP 범위 |
| --- | --- |
| 트랙 수 | 1개 |
| 입력 | INMP441 I2S 마이크 |
| 출력 | PCM5102A I2S DAC |
| 저장장치 | SD 카드 + FatFs |
| 표시장치 | GMG12864-06D LCD |
| 조작장치 | MCP23017 기반 버튼, KY-040 로터리 엔코더, 포텐셔미터 |
| FX | IFX 1개, TFX 1개 |
| FX 후보 | LPF, HPF, EQ, Reverb |

## 4. 제외 범위

### 4.1 MVP에서 명확히 제외할 기능 목록

본 프로젝트는 루프스테이션 시스템 프로토타입 구현이 목표이므로 실제 루프스테이션에서 제공하는 기능들 중 일부분은 구현하지 않는다. 제외할 기능들은 다음과 같다.

- 트랙 원샷 모드
- 트랙 팬 모드
- 트랙 플레이 모드
- 트랙 시작/종료 모드
- 트랙 길이 설정(본 프로젝트에서는 무조건 AUTO로 둔다)
- 트랙 루프 싱크
- 트랙 템포 싱크
- 리듬 설정(본 프로젝트에서는 리듬 기능 자체를 미제공한다)
- 마스터 설정
- phrase 메모리
- Assign
- MIDI
- 팬텀 파워
- 트랙 LED 커스터마이징
- 자동 정지
- 입력 라인 아웃 설정(본 프로젝트에서는 무조건 입력에서 출력으로 흐르도록 설정한다)
- 출력 라인 아웃 설정(본 프로젝트에서는 라인아웃과 출력이 동일하므로 무조건 출력으로 흐르도록 설정한다)
- USB 연결 모드

### 4.2 멀티 트랙 확장 여부와 시점

프로토타입이 완성되고 [test_plan.md](../verification/test_plan.md)에 작성된 테스트를 모두 통과할 때 멀티 트랙 확장을 시도한다.

초기에는 2개의 트랙으로 테스트를 진행하고, 테스트를 모두 통과하는 경우 5개까지 늘려 테스트를 진행한다. 확장 과정에서 기능이 추가되거나 기존 기능들이 수정되어야 한다면 이를 문서에 먼저 갱신한 후 기능을 수정한다.

### 4.3 외부 오디오 라인 입력 지원 여부

본 프로젝트의 프로토타입 구현 단계에서는 외부 오디오 라인을 지원할 계획은 없고, 멀티 트랙 확장에 성공한 이후에는 XLR 마이크를 시스템에 연결할 수 있도록 앰프 회로에 대해 공부할 계획이다.

### 4.4 USB 오디오 또는 MIDI 지원 여부

구현 계획은 없으나 프로토타입 개발이 완전히 끝난 후 개선 과제로 남겨둔다.

### 4.5 배터리 구동 또는 전원 관리 범위

보드에서 지원하는 전원으로 동작하고, 배터리로 구동하지 않는다. 구현 단계에서는 stlink 디버거로부터 전원을 공급받고, 테스트가 끝났을 때에는 USB-C타입 충전기를 보드에 연결하여 전원을 공급받도록 한다.

## 5. 대상 사용자 및 사용 상황

- 대상 사용자 : 상용 루프스테이션(RC-505)을 경험해본 사람
- 사용 환경 : 실내
- 사용자의 기술 수준 : 루프스테이션으로 간단한 드럼셋 구성 및 FX로 음향 효과를 입힐 줄 아는 수준

현재 문서에서 확인되는 사용 상황은 다음과 같다.

- 사용자가 버튼으로 녹음, 재생, 정지, 오버더빙 상태를 전환한다.
- 사용자가 FX 버튼과 노브로 입력 FX 또는 출력 FX를 선택하고 조절한다.
- 사용자가 LCD에서 시스템 상태, 트랙 상태, FX 상태를 확인한다.

## 6. 핵심 기능

| 기능 | 설명 |
| --- | --- |
| 오디오 passthrough | INMP441에서 들어온 오디오 데이터를 SAI1을 통해 DAC로 출력한다. |
| 트랙 녹음 | 오디오 입력을 트랙 데이터로 저장한다. |
| 반복 재생 | 저장된 트랙을 반복 재생한다. |
| 오버더빙 | 반복 재생 중인 트랙 위에 새 오디오를 추가한다. |
| FX 적용 | 입력 또는 출력 오디오에 FX를 적용한다. |
| UI 표시 | LCD와 LED로 시스템 상태를 표시한다. |
| 사용자 입력 | 버튼, 엔코더, 포텐셔미터로 시스템을 조작한다. |
| 파일 저장 | SD 카드와 FatFs로 트랙 파일을 저장하고 읽는다. |

## 7. 성공 기준

| 단계 | 성공 기준 |
| --- | --- |
| 하드웨어 bring-up | LCD, 버튼/LED 확장, ADC, SD, 엔코더, 오디오 입출력이 각각 단독 테스트를 통과한다. |
| 오디오 입출력 | INMP441 입력을 DAC로 passthrough할 수 있다. |
| 저장장치 | SD 카드 마운트와 파일 입출력이 가능하다. |
| 트랙 상태 | `IDLE`, `RECORDING`, `PLAYING`, `OVERDUBBING`, `STOPPED` 상태 전이가 동작한다. |
| UI | LCD와 LED가 현재 시스템 상태를 사용자가 이해할 수 있게 표시한다. |
