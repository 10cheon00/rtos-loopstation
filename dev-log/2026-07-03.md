# 화면 디자인 레이아웃 확정

photopia를 사용하여 128x64 lcd에 출력될 기본 레이아웃을 확정하였고, 이를 이미지화하여 문서에 추가했다. 기본 레이아웃을 바탕으로 패널 레이아웃을 구성하고 각 패널마다 레이아웃이 상이하므로 각 패널의 레이아웃을 문서에 추가했다.

# 에셋 추가

RC505 MK2에 적용된 폰트 디자인을 카피해 bdf파일로 만들고, bdfconv 툴을 사용하여 C배열화 시킨 후 프로젝트에 추가하여 출력하는 것에 성공했다. 커스텀 폰트를 기본으로 사용하기로 하되 크기가 큰 폰트가 필요한 상황은 u8g2에서 지원하는 기본 폰트로 해결할 계획이다.

추가적으로 패널마다 필요한 아이콘이나 위젯들을 찾아보았는데, 위젯은 모두 직접 만들어야 함을 알았고 아이콘들은 기본적으로 지원하는게 있으나, 아이콘들을 전부 포함해서 쓰면 메모리를 많이 차지하게 됨을 알게 되었다. 그래서 필요한 아이콘도 커스텀 에셋으로 만들어 프로젝트에 포함시켜야 한다.
