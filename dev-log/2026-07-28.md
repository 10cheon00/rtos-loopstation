# 문서 간소화

기존에는 미사여구들이 많이 붙은 문서들을 기능 문서랍시고 두었지만, 너무 많은 글들이 있어서 어떤 기능을 개발하겠다는게 눈에 들어오지 않았다.

그래서 핵심 내용만 남기고 나머지는 싹 제거하기 위해 현재까지 작성했던 문서들을 전부 레거시로 처리해 치웠다. 

요구사항은 변하지 않았으므로 요구사항을 기반한 설계 문서를 다시 작성하고, 새로 작성된 설계 문서를 바탕으로 현재까지 작성했던 코드들만 기능 문서로 확인할 수 있게 작성했다.

# 폴더 컨벤션 정리

현재까지 암시적으로 지켜왔던 컨벤션들을 명시적으로 바꾸기 위해 새로 문서를 작성했다.

# 하드웨어 변경

패널 당 4개의 파라미터를 화면에 출력할 수 있다. 그러므로 동시에 4개의 파라미터를 수정할 수 있도록 엔코더를 4개로 확장해야한다. 어제 빵판을 뜯고 점퍼선들을 다시 연결해서 4개의 엔코더를 연결할 수 있는 환경으로 하드웨어를 바꾸었다. 현재 ky-040 로터리 엔코더를 사용하고 있어서 결합이 불안정한데, ec11을 사용해서 바닥에 꽂을 수 있는 형태로 만들려한다. 이거는 사실 나중에 해도 되니까 급한건 아니다.
