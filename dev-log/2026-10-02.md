# 볼륨 페이더 구현 2

단순히 각 샘플마다 볼륨값을 0.0~1.0으로 정한 후 곱했다. 곱셈 과정에서 기존 BitDepth_t 타입이 uint32_t 였던걸 int32_t로 바꿨다. 기존 코드는 녹음된 데이터에 어떠한 수정도 가하지 않아서 문제가 없었지만, 이제는 볼륨값을 곱할 때 음수 샘플도 들어올 수 있기 때문에 int32_t를 BitDepth_t로 정했다.

# 트랙 초기화 구현

정지 버튼을 꾹 누르거나 정지 버튼을 연타하는 경우 정지 상태로 전이된 후 트랙을 초기화시키는 기능을 구현했다. 입력 태스크에서 홀드와 더블 탭을 처리하기 위해서 인터럽트가 발생하기를 무한히 기다리는 기존 코드를 고쳤다. 더블 탭과 홀드를 각각 체크하기 위해 이전 버튼의 상태와 시간을 기록한 후 인터럽트를 기다려야 할 가장 가까운 미래의 시간까지만 대기하도록 고쳤다.
