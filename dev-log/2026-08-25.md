# 패널 설계 확정

좌우 화살표 출력도 page_index를 이동 시킬 수 있냐에 따라 출력하도록 수정했다. 좌우 버튼을 누르면 page_index를 증가시키거나 감소시키도록 구현했다.

# 오디오 태스크 구현

오디오 태스크를 구현하기 앞서 이 태스크에서 수행하는 작업을 나열해야한다. 

- SAI1 페리퍼럴을 다룬다.
- 녹음 시작 메시지와 종료 메시지를 받는다.
- 오버더빙 시작 메시지와 오버더빙 종료 메시지를 받는다.
- 재생 메시지와 정지 메시지를 받는다.
- 삭제 메시지를 받는다.
- 받는 메시지에 따라 오디오 데이터를 다룬다. 필요에 따라서 저장 장치 관리 태스크에게 요청을 넣는다.
- IFX 활성화 메시지와 비활성화 메시지를 받는다.(이건 파라미터 조회를 직접 해야하는건가? 그럼 디스플레이 출력 태스크에서 파라미터를 복사하여 출력했던 건?)
- TFX 활성화 메시지와 비활성화 메시지를 받는다.
- 받는 메시지에 따라 SAI1의 입력 데이터와 출력 데이터에 FX 처리를 한다.
- 녹음 종료 시점을 박자에 따라 예측된 미래 또는 이미 정해진 트랙의 길이로 예측된 미래로 정한다.

대략적으로 위 리스트를 전부 구현하면 트랙 1개는 구현이 된다.

트랙을 2개 이상으로 한다면 다음 기능들도 구현해야한다.

- 두 개 이상의 트랙이 재생되고 있다면 루프 싱크를 맞추어야 한다.
- 두 개 이상의 트랙이 재생되고 있을 때 각 트랙은 마스터 템포에 맞춰 재생되어야 한다.
