# 설계/기능 문서 초안 작성

이제 V-모델 개발 프로세스를 조금 따라서 요구사항에 기반한 설계, 설계에 기반한 기능 문서를 작성했다. 전부 진행한 건 아니고, 버튼 입력, 디스플레이 패널 출력 기능부터 진행할 생각이다. 
일단 첫 스프린트를 진행한 다음 스프린트에서 느낀 점을 바탕으로 기능 문서를 작성할 때 개선하려고 한다. 작은 스프린트를 계속 진행하면서 프로젝트를 완성해갈 계획이다.

# I2C 인터럽트

GPIO를 폴링으로 받는 것보다 인터럽트로 받는게 맞다 생각해서 EXTI를 쓰면 되나 싶었는데 MCP23017에 모든 GPIO를 물려둔 상태이므로 I2C 인터럽트를 받으면 된다고 생각했다. 기능 문서, 설계 문서에도 이 내용은 작성하고, 기능 구현 때 확인해볼 계획이다.
