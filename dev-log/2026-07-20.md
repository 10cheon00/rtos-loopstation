# 디스플레이 상태 머신 전이 확인

CubeMX로 정의된 큐의 원소 타입이 부정확한 것을 고치고, 디스플레이 출력 명령 큐에 들어갈 메시지를 임의로 정의 후 디스플레이 출력 태스크에서 메시지에 따라 UI를 출력하도록 구현했다. 좌우 버튼으로 빠르게 전환해도 UI가 문제 없이 출력되지만, LCD 디스플레이 특성 때문인지, 느리게 지워지는 것 같다.

# UI 디자인 구현

`docs/old-2/`에 남아있던 bmp파일을 참고하여, 홈 패널과 설정 패널의 간단한 디자인을 구현했다. 홈 패널은 공통 디자인만, 설정 패널은 아이콘과 라벨까지만 출력했다. 이제 엔코더로 커서를 움직여서 하위 패널로 진입할 수 있게 만들어야 한다. 엔코더 입력을 받도록 구현하고, 설정 패널 상태에서는 커서 값을 두고 외부 입력에 따라 변할 수 있게 만들어야 한다.
