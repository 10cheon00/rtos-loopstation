# 상태 관리 태스크 코드 개선

RtosMessage 구조체에 의존하던 함수들을 개선했다. 이벤트 큐 메시지를 그대로 넘기지 말고, 먼저 메시지를 std::variant에 담고, 그 과정에선 RtosEnumValue와 같은 값들을 전부 실제 값으로 변환했다. 메시지를 실제 값들을 멤버로 갖는 구조체로 변환하였고 std::variant의 보관 여부에 따라 함수에 인자를 다르게 넘겼다. 함수 내부에서는 현재 Page에서 엔코더로 변경 가능한 파라미터를 가져오는 코드를 분리했고 그 과정에서 std::optional을 써서 예외처리하던 코드를 개선했다. SlotPosition이름을 SlotIndex로 고쳐서 사용 의도를 명확하게 만들었다.

# 볼륨 페이더 구현

우선 이 볼륨 페이더가 Adc 변환값을 가져오므로 0~65535 범위의 값을 0~100의 범위로 스케일해야했다. 먼저 스케일한 값을 ADC변환값이라는 파라미터에 저장한 후 나중에 FX파라미터 처리 시 활용하기로 했다.

# 향후 계획

상태 관리 태스크의 리팩토링은 이정도로 마치고, 핵심 기능들을 구현해야한다. 트랙 정지 버튼을 꾹 누르거나 연타하여 트랙을 초기화하는 기능부터 구현해야한다. 다른 기능들은 납땜이 필요한 부분이다. 날 잡아서 납땜해야겠다.
