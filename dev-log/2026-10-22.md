# Ui 상태 내에서 페이지 그룹 전환

페이지 그룹을 전환하지 않는 상태과 전환할 수 있는 상태를 구분했다. 페이지 그룹이 절대 바뀔 일이 없는 상태(홈 화면, 설정 화면, 시스템 설정 화면 등)들은 고정 페이지 상태로 구현하고, Fx 설정 화면이나 트랙 설정 화면들은 Fx 섹션과 슬롯, 트랙 번호에 따라 다르기 때문에 페이지 그룹이 바뀌는 상태로 구현했다. 

Fx 페이지 그룹의 경우 각 Fx별로 페이지 그룹을 미리 생성하고, Fx 타입에 매핑된 설정에 따라 런타임에 직접 교체하도록 구현했다. 지금은 Fx 패널밖에 없기 때문에 상태 Id가 정확히 FX_EDIT이면 선택한 Fx 타입과 섹션, 슬롯을 통해 페이지 그룹과 라벨을 업데이트하도록 했다. 

# LPF 구현(wip)

butterworth 방식의 lpf를 차분방정식으로 정리한 후(이건 6월 중에 이론적으로 했었다.) 오디오 태스크에서 믹싱 전에 적용하도록 구현했다. Rc505와 완벽히 똑같은 필터는 아니고 내 임의대로 구현한 필터이므로 공식이 똑같지 않다.

## 공식 유추하기

[FILTER EFFECT RC505 EXPLAINED [MK1] [MK2] – TRACKONE](https://trackonebbx.com/blogs/effects/rc505-explained-filter-mk1-mk2)

Cutoff 파라미터의 주파수 값은 위 링크에서 얻을 수 있었다. 

resonance의 경우 butterworth 필터의 Q값과 함께 생각하여 0.707 ~ ? 정도로 생각하고 있고, 파라미터 값으로 실제값을 만드는 공식은 아직 미완성이다.

나머지 rate와 depth에 대한 추측을 위해 직접 Rc505에서 출력된 신호를 녹음 후 audacity로 분석한 결과 resonance가 100일 때 아래 사진과 같이 삼각파가 등장하는 것을 확인했다. 

 ![image.png](https://i.imgur.com/dVcsoYq.jpeg)

따라서 Cutoff 주파수에 더해질 Lfo는 사인파가 아니라 삼각파로 처리해야함을 알게 됐고, depth를 100으로 설정하면 삼각파 파형이 30 hz ~ 7 khz 범위를 벗어나는 것을 보아 cutoff 주파수의 범위를 최대 진폭으로 설정했다. 

rate는 두 가지 방식이 있는데, 하나는 bpm에 의존하되 음표로 나타낸 주기이고, 다른 하나는 bpm과 독립적이되 0~100사이의 값으로 표현한 주기이다. 아직 bpm 기능이 없으므로 일단 bpm과 독립적인 rate를 먼저 구현했다. 녹음된 파형에서 다양한 주기로 테스트했고 측정한 파형을 AI로 분석해 주기시간을 구한 후 공식을 세워 테이블화했다. 

Rc505의 필터처럼 resonance가 100일 때 cutoff주파수 주변만 깔끔하게 들리지 않아서, resonance를 변경했을 때 어떻게 들리는지도 알아봐야할 문제다.
