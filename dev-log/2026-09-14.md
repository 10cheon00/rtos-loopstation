# 끝이 안보이는 납땜...

토요일부터 납땜을 시작했다. 30awg짜리 선만 주문했더니, 선을 벗길 니퍼?같은 도구가 필요해서 나중에 주문하느라 지연되었다. 그것뿐만 아니라 개발 보드를 교체하는 건, 개발 보드에 필요한 암소켓도 주문하는 것에 실수해서 더 지연되었다.

어쨌든 만능기판에 모든 부품을 납땜하려고 했는데 생각외로 시간이 너무 걸렸다. 단순 모듈만 납땜할 땐 핀헤더를 pcb보드에 결합하는 것이 끝이었지만, 만능기판에 납땜하는 건 핀헤더를 기판에 납땜하는 것과 구리선을 납땜된 부위에 한 번 더 납땜을 하는 거라서 작업하는데 시간이 두 배로 걸렸다. 

어찌저찌 모듈을 모두 기판에 장착하고 구리선을 납땜하려고 하니 선의 끝 부분 피복을 벗긴 후 손으로 선을 잡고 납땜하는 과정이 익숙하지 않았다. 나중에 핀셋을 하나 가져와서 수월해졌지만 선을 확장하여 다른 모듈들과 연결하는 작업이 처음이다보니 굉장히 오래 걸렸다. 책상 위에서 하지 않고 늘 하던대로 바닥에서 하니까 자세도 불편해서 중간에 쉬어야 했다.

토요일에는 3시간동안 작업을 했지만 절반도 못끝냈다. 약속이 있어서 그만뒀고, 나머지 작업은 일요일에 이어서 했다. 일요일에는 전원 라인을 전부 연결하는데 성공했고 mcp23017의 한 쪽 부분을 일부 연결하는 것에 성공했다. 여기까지 작업한 후 디버깅을 해보려고 했는데 합선이 나서 부품이 망가질까봐 불안스러웠지만 다행히도 디버깅이 정상적으로 진행되었고, 버튼 입력에 대한 인터럽트와 LED 토글에 성공했다. 중간에 C 코드에서 C++ 코드로 리팩토링을 했고 이에 대한 테스트를 해보지 않았기 때문에 하드웨어 문제인지 소프트웨어 문제인지 판단이 안 될 수 있었는데, 이러한 문제도 발생하지 않아서 다행이었다.

월요일에는 반대편에 있는 mcp23017도 납땜을 일부 완료했고 테스트 결과 정상 작동하였다. 이제 만능기판에 납땜하는 작업도 빠르게 할 수 있다.

현재까지 납땜되지 않은 부품 목록은 다음과 같다.

- System / Loop Setting? 버튼
- PCM5102A, INMP441
- 트랙 1 Edit / 재생 / 정지 버튼
- 트랙 1 RGB LED 

버튼과 LED들은 빠르게 끝낼 수 있다. PCM5102A도 교체 계획이 없으므로 그대로 납땜하면 된다고 생각한다.

INMP441은 만능기판에 그대로 납땜하면 안되고, 1x3짜리 암소켓에 점퍼선을 꽂는 형태로 생각중이다. 아직 부품이 도착하지 않아서 이 모듈은 배송이 오는대로 납땜하면 된다. 배송은 화요일이나 수요일에 올 것 같다.
