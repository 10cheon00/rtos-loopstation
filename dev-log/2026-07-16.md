# 버튼 입력 인터럽트 처리 구현

버튼 입력 시 MCP23017의 INTA핀으로부터 인터럽트 이벤트가 발생한다. 이를 위해 MCP23017을 인터럽트 모드로 동작시켜야 한다. 이는 MCP23017의 GPINTENn레지스터에 각 핀 번호별 동작 방법을 씀으로 설정한다. 올바른 핀 출력을 얻기 위해 여러 MCP23017의 레지스터에 쓰기 작업을 수행한다. 

> 여기까지 mcp23017.c에 구현했다.

이제 버튼을 입력하면 EXTI 인터럽트가 발생하고, 하나의 MCP23017마다 EXTI 번호를 다르게 할당하여, ISR에 전달되는 핀 번호로 MCP23017을 구분한다. 핀 번호 + 틱 카운트를 mcp23017_int_event_queue에 넣음으로 ISR의 실행은 끝난다.

> 여기까지 main.c에 구현했다.

InputTask에서는 이를 수신하고, 핀 번호로 MCP23017 모듈을 구분한 후 해당 모듈의 I2C INTn, INTCAPn 레지스터를 읽어 어느 핀이 인터럽트를 일으켰는지, 핀들의 상태가 어떠한지 확인한다. 관련된 정보를 추출한 후 루프스테이션의 어느 버튼인지 설정값을 조회하여 ControlButtonPayload를 만들고 이를 상태 관리 태스크에 전달한다.

> 여기까지 input_task.c에 구현했다.

# 공통 설정값이나 정보 파일

json같은 파일은 쓸 수 없으므로 c파일에 배열과 구조체를 정의함으로 공통 설정값을 정의했다. 버튼 종류는 `types/control_button.h`에, MCP23017 모듈별 할당된 버튼 종류는 `tasks/input/input_config.h`에 정의했다. 

이제 입력 버튼을 누르면 상태 관리 태스크로 전달되게 구현했으므로, 이를 통해 디스플레이 패널 조작을 구현할 계획이다. 

계획은 내일 세워봐야겠다.
