# 설계 변경

저번에 판단했던 대로 FX 설정 패널에서 여러 개의 파라미터를 출력할 수 있도록 패널 내부에 페이지를 두고 페이지에 따라 파라미터나 메뉴 아이콘을 출력하는 구조로 수정했다. 이에 따라 특정 패널에 강하게 결합된 렌더러 파일이 필요없어졌고, 디스플레이 태스크에서 직접 렌더러 함수를 호출한다. 특정 패널을 출력하는 렌더러 함수 대신, 기존에 작성했던 메뉴 아이콘 출력이나 파라미터 출력 함수를 사용한다. 

이 과정에서 enum이나 id들의 네이밍이나 선언 위치가 컨벤션대로 되지 않았기 때문에 이건 전체적으로 날 잡고 리팩토링해야겠다.

기존에는 패널 전이에 대한 설정을 각 패널이 들고 있도록 했는데, 전역 버튼에 의한 패널 이동이 필요해짐에 따라 패널 전이 설정을 각 패널이 가지고 있을 필요가 없어졌다. 전역 버튼에 의한 패널 전이를 별도 설정으로 보관하고, 패널 내에서는 패널이 보여줘야 할 메뉴 아이콘이나 파라미터만 보관한다. 그리고 현재 몇 페이지를 출력하고 있는지도 기억하고 있도록 했다. 

Exit 버튼은 상위 패널로 이동하게 되므로, 이를 구현하기 위해서는 어떤 패널의 상위 패널 정보를 기억해야한다. 그러나 이걸 구조체에 넣는 건 설정이 분산되는 거라고 판단해 별도 설정으로 분리했다. 

좌우 버튼은 오로지 페이지 이동에만 사용되므로, 현재 패널의 페이지 인덱스변경에만 사용하면 된다. 아직 구현하지 않았다.
