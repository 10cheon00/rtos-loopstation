# 로터리 엔코더 작동 확인

이전에 샀던 엔코더 말고 다른 엔코더를 샀는데 이건 정상 작동한다. 기판이 원형이어서 마음에 안들지만 받아들이기로 했다. 근데 한 번 회전할 때마다 2씩 올라가는 것이 문제여서, 이걸 수정해야한다.

# 모든 상태 머신 구현

트랙 상태 표시 LED를 구현하기 위해 먼저 트랙 상태 머신을 구현하고, 현재 트랙의 ID를 메시지에 담아 전송했다. 디스플레이 태스크에서는 상태에 매핑된 GPIO정보를 바탕으로 i2c에 명령을 보낸다.

시스템 상태 머신을 구현했고, 최초 상태(NOT_INITED)에서 등록된 설정들의 커버리지를 검증하도록 구현했다. 여기서 커버리지란, 한 맵(A)의 값 타입을 키 타입로 사용하는 다른 맵(B)이 있을 때, A맵의 모든 값이 B맵의 모든 키로 존재하는 지의 여부를 말한다. 

이제 검증 로그를 보고 커버리지가 100%가 되도록 전체적인 설정을 수정하고, 구현되지 않았던 패널을 구현해야겠다.
